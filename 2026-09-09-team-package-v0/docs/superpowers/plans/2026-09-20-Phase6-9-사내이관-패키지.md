## 이 작업의 진짜 위험 — 이 PC 에서는 한 줄도 실행해 볼 수 없다

Docker 가 없다. 스크립트는 **문법 검사(`bash -n` · PowerShell 파서)와 구조 검사 테스트**까지만 여기서 되고, 실제 `docker save/load/compose up` 은 사용자 측 Docker PC 에서 처음 돈다. 그래서:

- 스크립트는 **짧고 직선적**으로 — 분기와 재주를 부리지 않는다. 틀리면 첫 실행에서 드러나야 한다.
- 실패 지점마다 **무엇을 확인하라**는 메시지를 낸다(포트 충돌·이미지 없음·`.env` 없음·헬스체크 실패).
- 오프라인 서버에서는 **절대 빌드하지 않는다** — `compose up` 에 `--no-build`. 빌드가 걸리면 인터넷이 없어 조용히 오래 실패한다.

## 설계 — 파일과 흐름

```
인터넷 PC (git clone 가능)                        사내 서버 (인터넷 없음)
─────────────────────────────                    ──────────────────────────────
deploy/onprem/build_image.{sh,ps1}               deploy/onprem/load_and_run.{sh,ps1}
  docker build --build-arg APP_COMMIT=<sha>        docker load < tar.gz
  docker save → threeon-budget_<sha>.tar.gz         docker tag <sha> → latest
  sha256 파일                                       .env 존재·필수 키 확인
        │                                           docker compose up -d --no-build
        │  USB/반입 승인:                            헬스체크 대기(최대 90초) → /healthz 출력
        │   tar.gz · .sha256 · deploy/ 폴더 · .env
        └──────────────────────────────────────►  deploy/onprem/check.{sh,ps1}
                                                    컨테이너 상태·/healthz·헤더·볼륨·디스크
```

| 파일 | 책임 |
|---|---|
| `deploy/Dockerfile` | `ARG APP_COMMIT` → `ENV APP_COMMIT` — `/healthz` 의 `commit` 이 사내에서도 찍히게(Render 는 `RENDER_GIT_COMMIT` 이 우선, 변화 없음) |
| `deploy/onprem/build_image.sh` · `.ps1` | 인터넷 PC. 태그 `threeon-budget:<sha>` + `latest`, `docker save \| gzip`, SHA256 |
| `deploy/onprem/load_and_run.sh` · `.ps1` | 서버. load → tag latest → `.env` 검사 → `compose up -d --no-build` → 헬스체크 대기 |
| `deploy/onprem/check.sh` · `.ps1` | 운영 점검. 언제든 실행 |
| `.env.example` | 죽은 키(`FORECAST_URL`·`BASIC_USER`·`APP_ENV`) 제거, compose 가 읽는 키(`HOST_PORT`·`PG_*`) 추가, **두 위치**(로컬 `app/.env` · Docker `루트/.env`) 명시 |
| `docs/사내이관_가이드.md` | 절차 1개 — 준비물 → 이미지 만들기 → 반입 → 기동 → 점검 → 운영(백업·업데이트·롤백) → HTTPS → 문제 해결 |
| `app/tests/test_onprem_package.py` | 구조 검사 — 위 파일 존재·`--no-build`·`APP_COMMIT` 전달·`.env.example` 키가 코드/compose 가 읽는 것과 일치·가이드 필수 절 |

**하지 않는 것:** 데이터 이전(별건) · HTTPS 종단(사내 프록시 몫, 가이드에 `COOKIE_SECURE=1` 만) · Windows 서비스 등록(compose `restart: unless-stopped` 가 대신한다 — Docker Desktop 자동 시작만 켜면 됨).
