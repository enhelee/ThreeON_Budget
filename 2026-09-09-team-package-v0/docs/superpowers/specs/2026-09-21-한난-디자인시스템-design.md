## 1. 목적과 결정

이 앱은 팀 5~10명이 매일 여는 **업무 도구**다. 지금 화면은 시안 없이 Tailwind 기본 팔레트(파랑 `blue-600` 강조·`slate` 중성)로 자란 것이라 기관 정체성이 없고, 화면마다 파랑의 농도가 제각각이다. 한난 메인 시안이 확립한 «넓은 여백·명료한 정보·절제된 브랜드색·따뜻하고 신뢰감 있는 인상»을 이 앱의 **업무 도구 구조(사이드바) 위에** 입힌다.

| 결정 (사용자, 2026-09-21) | 내용 |
|---|---|
| 범위 | **전면 적용** — 토큰·공통 컴포넌트·셸(사이드바·헤더·게이트·로고)·화면 10개의 색 유틸리티 일괄 치환 |
| 레이아웃 | **사이드바 유지**. 시안의 상단 메뉴로 바꾸지 않는다(메뉴 7개·업무 흐름·기존 라우터 유지) |
| 브랜드색 규칙 | **시안 규칙 그대로** — 주요 버튼은 검정 바탕+흰 글자+빨간 테두리, 빨강은 포커스·활성 표시·작은 강조에만. 넓은 면은 흰색·중성색 |
| 글꼴 | **제목에만 한난체**(자체 호스팅 서브셋), 본문·표·숫자는 Pretendard 계열 유지 |

**하지 않는 것:** 레이아웃 재배치 · 새 기능 · 다크 모드 · 시안의 마케팅 섹션(첫 화면·소식·고객지원) 이식 · 사이드바 → 상단 메뉴 전환.

## 3. 토큰

`app/web/src/styles/app.css` 의 `:root` CSS 변수 + `tailwind.config.js` `theme.extend.colors` 로 **같은 값을 두 이름으로** 노출한다(CSS 변수는 손으로 쓴 `custom.css` 용, Tailwind 이름은 뷰의 유틸리티용).

```
/* 중성 (시안 = openai-light) */
--bg-base #FFFFFF   --bg-subtle #F7F7F8   --bg-overlay rgba(13,13,13,.56)
--text-primary #0D0D0D   --text-secondary #5D5D5D   --text-tertiary #8F8F8F   --text-disabled #A6A6A6
--border-default #E5E5E5   --border-subtle #F2F2F2   --border-strong #C9C9C9
/* 브랜드 (CI 매뉴얼) */
--brand #FE0009   --brand-ink #000000
/* 상태 (의미 전달 — openai-light 시맨틱) */
--success-fg #16794A / --success-bg #EAF5EF   --warning-fg #9A6700 / #FFF4D6
--error-fg #B42318 / #FDECEC   --info-fg #315EAC / #EAF2FF
/* 형태·모션 */
--radius-card 16px   --radius-visual 24px   --radius-button 999px   --radius-control 12px
--shadow-float 0 8px 24px rgba(0,0,0,.10)   (일반 카드는 그림자 없음)
--duration 180ms   prefers-reduced-motion → 애니메이션·부드러운 스크롤 억제
```

Tailwind 이름: `ink`(=text-primary) · `sub`(=text-secondary) · `tri` · `dis` · `line`/`line-strong`/`line-subtle` · `base`/`subtle` · `brand`/`brand-ink` · `ok`/`ok-bg` · `warn`/`warn-bg` · `err`/`err-bg` · `info`/`info-bg`. 기존 `slate-*`·`blue-*` 는 **치환 뒤 남기지 않는다**(테스트로 고정, §8).

## 4. 타이포그래피

| 역할 | 글꼴 | 크기/굵기/자간 |
|---|---|---|
| 화면 제목 `#pageTitle`·뷰의 `h2`(«전체 지사 현황 — 2025년» 류)·게이트 `h1`·`.section-title` | **HananCha** → Pretendard 스택 폴백 | 화면 제목 22px/600/−.02em · 뷰 h2 28px(모바일 24px)/600/−.03em · 섹션 제목 18px/600 |
| 본문·표·입력·배지·숫자 | Pretendard → Apple SD Gothic Neo → Malgun Gothic → system-ui | 본문 15px/1.6 · 표 13~14px · 캡션 12~13px. **숫자 열은 `font-variant-numeric: tabular-nums`** |
| 지표 카드 큰 숫자 | Pretendard(가독·정렬) | 28~32px/700/−.02em |

한난체는 `pyftsubset` 으로 **KS X 1001 완성형 2,350자 + ASCII + 기본 기호**만 남겨 woff2 로(예상 200~300KB). `app/web/public/assets/fonts/HananCha-v1.woff2` 에 두고(§9 — `/assets/*` 의 immutable 캐시를 받기 위해, 교체 시 `-v2` 로 파일명 변경) `@font-face { font-display: swap }`. 제목에만 쓰므로 `unicode-range` 는 두지 않는다. 폰트 파일은 저장소에 커밋한다(사내 도구 자산).

## 5. 셸

**사이드바(`index.html`·`components/sidebar.js`)** — 폭 288px 유지. 흰 배경·오른쪽 `line` 1px. 상단 로고 자리에 파란 아이콘 대신 **공식 시그니처 SVG**(`public/assets/kdhc-signature-ko.svg`, 폭 184px, `alt="한국지역난방공사"`, 밑에 «예산·실적 분석 · 발전플랜트 유지보수» 캡션 13px `sub`). 메뉴 항목: 44px 이상 높이, 글자 `sub` → 호버 `ink` + `subtle` 배경, **활성 = `ink` 굵게 + 왼쪽 2px `brand` 마커**(시안의 활성 메뉴 밑줄을 세로 메뉴에 옮긴 것). 태그 칩(H·1·2…)은 `subtle` 배경 `sub` 글자. 하단 안내 박스는 `subtle` 배경·`line` 테두리, 초록 점은 `ok`.

**헤더(`index.html`)** — 높이 72px, 흰 배경, 하단 `line` 1px, `backdrop-blur` 제거(시안은 불투명 흰색). 제목 한난체 22px. 연도 선택·«+연도»·«분석 실행»·작업자 배지·로그아웃은 §6 컴포넌트로. 작업자 배지는 `subtle` 배경 `ink` 글자(지금의 남색 제거).

**모바일 드로어(`main.js` `openMenu/closeMenu`)** — 지금은 열기·닫기뿐. 보강: ① `Escape` 로 닫기 ② 닫힌 뒤 **`#menuButton` 으로 포커스 복귀** ③ 열려 있는 동안 Tab 이 드로어 안에서 순환(첫/끝 요소에서 감싸기) ④ `aria-expanded` 를 버튼에, `aria-modal`·`role="dialog"` 를 사이드바에(모바일에서만) ⑤ 메뉴 항목 클릭 시 닫힘 유지. 배경은 `--bg-overlay`.

**로그인 게이트(`views/gate.js`)** — 같은 컴포넌트 클래스라 자동 적용. 파란 아이콘 → 시그니처 SVG, 제목의 파란 강조 → `ink` 굵게, 단계 칩 → `subtle`/`sub`.

**바쁨·토스트** — 토스트 `ink` 배경 흰 글자 24px 곡률 유지, 바쁨 오버레이 `--bg-overlay`, 스피너 색 `brand`.
