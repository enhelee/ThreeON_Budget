# 계획본 생성 프로그램 (1단계) — 설계 명세서

- 작성일: 2026-07-22
- 범위: **1단계 = 계획본만** (손익 계획 / 자본 계획). 실적본은 2단계(별도 명세).
- 형태: 로컬 웹앱(Streamlit), Python + openpyxl + pandas
- 기존 `budget_app` 을 진화(재활용 + 종합표 동적 생성 신규)

---

## 1. 목적

"사업별 예산" 파일(모든 사업의 계획 금액)을 업로드하면, 사용자가 웹에서 구성한 **지사(열)** 와
**예산과목(행)** 에 따라 **지사별·과목별 종합표**를 자동 생성한다. 손익/자본을 각각 실행해
`{연도}년 손익예산_계획.xlsx`, `{연도}년 자본예산_계획.xlsx` 를 만든다.

---

## 2. 입력

### 2.1 업로드 파일: "사업별 예산.xlsx"
- 시트 `양식1(월별)` 하나. **손익·자본 구분 없이 전체 사업** 포함.
- 헤더 3행, 데이터 4행부터. 컬럼:
  | 열 | A | B | C | D | E | F | G | H | I | J | K~V |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | 의미 | 주관부서명 | 예산귀속 부서코드 | **예산귀속 부서명(처.지사)** | 부서명(부) | 속성 | 예산코드 | **예산과목** | 사업명 | 산출내역 | **연예산 합계** | 1~12월 |
- 빈 템플릿을 웹에서 다운로드 제공(`사업별예산_템플릿.xlsx`).

### 2.2 내장 기준데이터
- `기준데이터.xlsx`(기존): `부서코드`(코드→처·지사), `예산코드`(예산과목→속성). 지사 기본 목록·소속 그룹 및 과목 기본 목록의 시드로 사용.

---

## 3. 실행 흐름 (웹 화면)

```
① 구분 선택        : [손익 계획] 또는 [자본 계획]  — 한 번에 하나만 실행
② 대상연도 선택    : 예 2026 (텍스트/드롭다운)
③ 지사 구성        : 저장된 {연도} 설정 자동 로드 → 수정 → [적용 완료](저장)
④ 예산과목 구성    : 저장된 {연도}+{구분} 설정 자동 로드 → 수정 → [적용 완료](저장)
⑤ "사업별 예산.xlsx" 업로드
⑥ [분석 실행] → 결과 요약(집계액·미분류 과목·결측치 건수) → 결과 다운로드
```

---

## 4. 설정 저장·기억 (영속화)

앱 폴더 `budget_app/config/` 에 JSON으로 저장하고 실행 시 자동 로드하여 이전 값이 채워진 상태로 표시.
`[적용 완료]` 시 현재 화면 상태로 덮어써 저장.

### 4.1 지사 구성 — `config/지사구성_{연도}.json`
- 그룹 4종 **고정**: 본사 / 중대형CHP / 소형CHP / DH.
- 항목 배열: `{ "이름": "화성지사", "그룹": "중대형CHP", "포함": true }`
- 기능: 포함/제외(체크), 이름 수정, **소속 그룹 이동**(드롭다운), 추가, 삭제.
- 시드 기본값(최초): 양식2/양식3 종합표의 표준 지사·소속.
  - 본사: 플랜트기술처·안전처·통합운영처·건설처·미래사업처
  - 중대형CHP: 동탄·화성·파주·광교·판교·삼송·대구·청주
  - 소형CHP: 수원사업소·광주전남·강남
  - DH: 중앙·고양사업소·용인·분당사업소·세종·김해사업소·양산·평택

### 4.2 예산과목 구성 — `config/과목구성_{연도}_{손익|자본}.json`
- 대분류 **고정**: 손익=수선유지비·지급수수료 / 자본=자산·예비품·A급정비·건설공사.
- 항목 배열: `{ "과목": "수선유지비-건물/구축물", "대분류": "수선유지비", "심의대상": true, "포함": true }`
- 기능: 포함/제외, 이름 수정, 대분류 이동, **심의대상 ON/OFF**, 추가(추가 시 손익/자본 지정), 삭제.
- 시드 기본값:
  - **손익(B안, 8과목)**: 수선유지비-건물/구축물(심의 ON), -열원정기점검, -열원경상정비, -열원정기유지보수, -열원보완및개선(심의 ON), -비저장품(보수자재), -소모품(자재공기구), 지급수수료-열원점검수수료
  - **자본(11과목)**: 자산[건물·구축물·기계장치·공구와기구-열원시설공기구], 예비품[저장품-열원(보수)·건설중인자산-재생고온부품·건설중인자산-자산화예비품], A급정비[외주비-열원정기점검], 건설공사[외주비-열원공사비·재료비-열원자재비·외주비-열원기술용역비]

## 5. 결과물 (구분에 따라 1개 파일)

- 손익 → `{연도}년 손익예산_계획.xlsx`, 자본 → `{연도}년 자본예산_계획.xlsx`
- 각 파일 시트: `종합표`, `양식1(월별)` (+ 결측치가 있으면 `결측치검토`)

### 5.1 `양식1(월별)` 시트
- 업로드 데이터에서 **선택 구분(손익/자본)의 과목 목록에 해당하는 행만** 필터.
- 원본 컬럼(A~J + 월별) 그대로 기록.
- **결측치 표시**(§7): 필수값 빈 셀을 색 강조 + 검증 메모.

### 5.2 `종합표` 시트 (동적 생성)
- **열 구조**: [구분 A:B] · 본사(선택 처 + 소계) · 중대형CHP(선택 지사 + 소계) · 소형CHP(선택 지사 + 소계) · DH(선택 지사 + 소계) · 합계. 선택된 지사만 열 생성, 그룹 헤더 병합.
- **행 구조**: 선택된 예산과목(대분류 병합), 심의대상 ON 과목은 `5천만원 미만`/`5천만원 이상(심의대상)` 2줄, 대분류 소계·전체 합계 행.
- **값**: 각 지사 열 = `SUMIFS('양식1(월별)'!연예산, '양식1(월별)'!예산과목=행, '양식1(월별)'!처지사=열헤더)`.
  - 심의대상 이상 = 위 조건 + 연예산 ≥ 50,000천원(원본 데이터에 심의 플래그 열을 추가해 참조); 미만 = 전체 − 이상.
  - 소계 = 그룹 내 지사 합, 합계 = 소계들 합.
- **서식**: 헤더/그룹/소계 스타일·테두리 적용(양식2/3 종합표 룩 참조). 살아있는 수식으로 엑셀 재계산 가능.

---

## 6. 손익/자본 분류 및 미분류 과목

- 업로드 각 행의 예산과목이 **선택 구분의 과목 목록**에 있으면 포함, 없으면 그 파일에서 제외.
- **미분류 과목 목록**: 손익·자본 어느 표준/구성 목록에도 없는 예산과목을 실행 후 **결과 요약과 `결측치검토`(또는 별도 안내)에 표시**해 담당자가 확인.

---

## 7. 결측치(missing value) 표시 — 담당자 수정 지원

- **대상 필수 필드**: 예산과목(G), 처지사(C), 연예산(J), 사업명(H).
- **처리**:
  1. `양식1(월별)` 출력 시, 필수 필드가 빈 행의 **해당 빈 셀에 강조 채움색**(예: 연한 빨강)을 적용하고, 행 끝 `검증` 열에 누락 항목 메모(예: "처지사 누락").
  2. 별도 `결측치검토` 시트에 (원본 행번호 · 사업명 · 누락 필드) 목록화.
- 예산과목 자체가 빈 행은 분류 불가 → `결측치검토` + 미분류 목록에 함께 표기(집계 제외).

---

## 8. 기술 / 모듈 구조

- Python 3.14, openpyxl, pandas, streamlit.
- 신규/재활용 모듈(단일 책임):
  - `config_store.py` — 지사·과목 구성 JSON 로드/저장/시드(신규)
  - `org_structure.py` — 지사→그룹 구조, 종합표 열 레이아웃 계산(신규)
  - `loaders.py` — 사업별예산 로더(재활용/보강: 결측치 원행 포함 반환)
  - `plan_summary.py` — 예산과목(행)×지사(열) 집계 + 심의 분리(신규, 기존 aggregator 대체)
  - `missing.py` — 결측치·미분류 과목 수집(신규)
  - `excel_plan_writer.py` — 동적 종합표(SUMIFS·서식)+양식1(결측치 강조)+결측치검토 시트 작성(신규, 기존 excel_writer 계획부 대체)
  - `pipeline_plan.py` — 계획 실행 오케스트레이션(신규)
  - `app.py` — Streamlit UI(구분·연도·지사구성·과목구성·업로드·실행·다운로드)로 개편
- 기존 `classifier`, `reference_data`, `config`(과목·지사 시드값), `similarity`(실적용, 이번 미사용)은 유지.

## 9. 엣지 케이스

- 업로드 파일명이 "사업별 예산"이 아니어도 진행(시트명 `양식1(월별)` 기준). 시트 없으면 명확한 오류.
- 선택된 지사에 없는 처지사의 사업 → 집계 제외 + 안내(미포함 지사 목록).
- 음수 연예산 그대로 합산.
- 저장된 설정이 없으면 시드 기본값으로 시작.

---

## 10. 성공 기준

- 손익/자본 각각 실행 시, 선택 지사·과목 구조의 종합표 + 필터된 양식1 시트가 생성된다.
- 종합표 합계 = 양식1(월별) 해당 구분 연예산 합계와 일치(엑셀 재계산 기준).
- 지사·과목 구성이 JSON에 저장되고 다음 실행 시 자동 로드되어 화면에 채워진다.
- 결측치 빈 셀이 색 강조 + `결측치검토` 목록에 표시된다.
- 미분류 예산과목이 실행 후 목록으로 표시된다.
- 원본 종합표 서식(그룹·소계·테두리) 유지.
