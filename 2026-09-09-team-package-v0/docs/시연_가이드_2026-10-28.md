# 경진대회 시연 가이드 — 더미 데이터 · 시연 서버 · 깨우기 · 녹화 (2026-10-28)

> 경진대회 전략 D. 발표에서 «데모 실패 0 · 실데이터 노출 0»을 만드는 준비물과 순서.
> 코드 `app/scripts/make_demo_db.py`(더미 DB) · `run_demo.py`(시연 서버) · `wake_prod.py`(운영 깨우기)
> · 실행 파일 `app/시연_실행(더미DB).bat` · `app/운영서버_깨우기.bat`.

## 1. 한눈에 — 무엇으로 시연하나

| 순위 | 무엇 | 왜 |
|---|---|---|
| 1 | **노트북의 시연 서버 + 더미 DB** | 콜드 스타트 없음(로컬) · 실데이터 없음 · 인터넷이 끊겨도 된다 |
| 2 | 운영 서버(10분 전 깨우기) | 노트북이 안 될 때. 실데이터라 화면 공유 범위 주의 |
| 3 | 녹화본 | 둘 다 안 될 때. 3분 흐름을 미리 찍어 둔다 |

## 2. 더미 데이터 — 최종기획서 «더미데이터화»에 적은 방법 그대로

```bash
python scripts/make_demo_db.py --src <실데이터 사본.db> --out "../../../시연용_더미DB" --unlock 2025
```

- 실데이터 사본 = 주간 백업(`문서\ThreeON_DB백업\<날짜>`)을 SQLite 로 옮긴 것. 운영 DB 에 직접 붙이지 않는다.
- **하나의 치환표**로 모든 표를 바꾼다:
  - 지사·사업소 → 지사A~V(지명 «화성»도 같은 «지사A» — 전표 «지사원문»에 지명만 적힌 행이 많아 같아야 지사로 정규화된다)
  - 열원 지명(상암·수서·동남권 …) → 지점가~
  - 업체명((주)·㈜·주식회사, 설비 제조사) → «(주)업체»·«제조사가~»
  - 작업자명 → 작업자1~
  - 금액 × 지사별 계수(0.8~1.2, 계획·전표에 같은 계수) · 전표번호 재부여 · 거래처코드 삭제
  - 본사 처 이름(플랜트기술처 등)은 그대로 — 본사 배분 규칙이 쓴다
- 일반 낱말 속 지명은 보호한다(«비용**용인**식», «확**대구**축», «**중앙**제어», «**일원**화»).
- 코드에 박힌 지사 별칭(«서울남부지사 → 강남지사» 등)은 치환한 이름으로 DB 별칭에 넣는다.
- 분석 결과는 지우고 앱의 분석으로 다시 만든다 → 매칭·총액 보존 구조가 실데이터와 같다.
- `--unlock 2025`: 시연의 «재배정 1클릭» 장면을 위해 그 해 마감을 풀어 둔다(2023·2024 는 마감 그대로).
- 함께 생기는 `치환표.xlsx` 에는 **실명**이 있다 — 공유하지 않는다.

**검증(2026-10-27 백업 사본):** 남은 실명 지명·작업자명 0건(스크립트가 마지막에 센다) · 연도·예산별 «계획집행 실적»이 실데이터 구조와 같다(예: 2025 자본 47,648,307천원 = 원본에 같은 계수를 곱한 값) · 시연 서버의 메인·검토 큐·3번·4번·5번·설정 화면 글자에 실명 0.

## 3. 시연 서버 (노트북)

1. `app/시연_실행(더미DB).bat` 더블클릭 → 브라우저가 `http://localhost:8020` 으로 열린다(로그인 없음).
2. 서버가 뜨면 전망·검토 큐 계산을 뒤에서 미리 채운다(1~2분). 발표 **5분 전**에 켜 둔다.
3. 창을 닫으면 서버가 꺼진다.

- 운영 DB 로 새지 않게 `DATABASE_URL`·`APP_PASSWORD` 를 빈 값으로 먼저 넣는다(`.env` 가 있어도 덮지 않는다).
- 더미 폴더 기본 위치 = 저장소 바깥 `중장기 예산 소요 전망\시연용_더미DB`. 다른 곳이면 `py scripts\run_demo.py <폴더> [포트]`.

## 4. 운영 서버 깨우기 (예비)

`app/운영서버_깨우기.bat` — 발표 **10분 전**. `/healthz?db=1` 이 DB 까지 응답할 때까지 부르고(잠든 서버 30~60초), 예열 150초를 기다린 뒤 «준비됨». 그다음 브라우저에서 로그인하고 메인 → 검토 큐 → 5번을 한 번씩 열어 둔다. (이틀마다 도는 keepalive 워크플로는 DB 일시정지 방지용이라 서버 잠듦은 막지 못한다.)
