## 1. 배경과 문제

한국지역난방공사 플랜트기술처는 해마다 발전플랜트(중대형 CHP·소형 CHP·DH 지사 19곳) 유지보수 예산을
세우고, ERP 실적과 대조하고, 10개년 중장기 소요를 전망한다. 지금까지는 담당자 1인이 엑셀로
약 3개월 걸려 했다.

| 문제 | 영향 |
|---|---|
| 계획 사업과 ERP 전표를 손으로 짝짓는다 | 사업별 집행률·미시행·신규를 내는 데 수주 |
| 표준금액(지사 × 과목 × 정비등급)을 엑셀 수식으로 손으로 만든다 | 지사마다 방식이 제각각, 수식 오류(V3 수정본에서 8건) |
| LTSA·고온부품·CRI 같은 정기비용이 평균에 섞인다 | 전망이 정비 주기를 따라가지 못하고 이중계상 위험 |
| 근거가 엑셀 셀 수식에 숨어 있다 | 누가 왜 그 금액을 썼는지 다시 설명하기 어렵다 |

## 2. 목표

1. **계획 → 실적 → 분석 → 표준화 → 10개년 전망**을 한 앱에서 끝낸다.
2. 숫자마다 **근거**(전표·규칙·연도)를 화면에서 따라갈 수 있게 한다.
   - 분석 뒤 사람이 볼 것을 **돈이 걸린 순**으로 한 줄에 세워, 적은 건수로 대부분의 금액을 확인하게 한다(검토 큐).
3. 기존 엑셀(예산표준화 V3)과 **같은 숫자를 재현**하고, 다른 칸은 이유를 보여 준다.
4. 담당자 3개월 → **수일**(업로드·검토·확정 중심).

성공 지표(현재 실측):
- 표준화 엔진이 V3 수정본 표준금액 437칸을 100% 재현한다(수식 해석 87%, 나머지는 엑셀 값 고정).
- 백테스트(마감 + 참고 실적, 시험연도 2021~2025): 과목 합계 오차 25~36%, 지사 3년 누적 15~20%.
- 운영 화면 전환은 로그인 후 2.9~5.5초, 전망 표는 7.4초(재방문 3.0초).
- 검토 큐(운영 2025 사본): 검토 줄 1,461건 중 상위 231건이 검토 금액의 80% — 건수 16% 로 금액 80% 확인. 처리 진행률은 금액 기준으로 잰다.

## 3. 사용자

| 사용자 | 하는 일 |
|---|---|
| 예산 담당(플랜트관리부) | 계획·ERP 업로드, 매칭 확인·재배정, 연도 마감, 표준화·전망 확정, 양식 내보내기 |
| 지사·팀원 | 지사별 실적·차이 사유 확인, 사유 입력 |

## 4. 범위 — 단계별 기능 요구사항

### 1단계 예산 계획
- 손익·자본·건설공사 계획본(xlsx) 업로드 → 사업 행 정규화(처지사·예산과목·연예산·사업명), 결측 검사.
- 심의 대상(≥ 50,000천원) 표시, 지사그룹 4종(본사·중대형CHP·소형CHP·DH) 고정 순서.

### 2단계 실적 집계·매칭
- ERP(zrfm2) 업로드 → 전표를 계획 사업에 매칭(사업명 유사도·학습·규칙) → 계획집행·신규·미시행·미반영.
- 전표 **재배정**(다른 사업·다른 지사·신규 이름) — 저장 즉시, 결과는 «분석 반영»에서. 학습은 설정의 [AI 학습]으로만.
- **연도 마감**: 마감 연도는 업로드·분석·재배정이 막히고 산출물 스냅샷을 남긴다. 해제는 사유 필수.

### 3단계 실적 분석
- 지사별 계획·실적·집행률(80~120% 초록, 80 미만 노랑, 120 초과 빨강), 계획–실적 산점도, 지사 상세(사업 → 전표 드릴다운, 매칭 근거).
- 집행률 ±20%p 를 벗어난 사업의 차이 사유 입력(마감 연도에도), 이상 알림.

### 3단계 검토 큐 (`✓ 검토 큐`, 2026-10-27)
- 사업 한 줄 = 검토 단위. 이유 넷(차이 ±20%p · 과다 귀속 · 음수 실적 · 저확신 귀속)을 모아 **검토 금액 × 위험 가중**(과다 귀속·음수 1.5, 저확신 1.2, 차이 1.0)으로 줄 세운다. 같은 돈은 한 번만 센다.
- «상위 N건이 남은 검토 금액의 80%» · 처리 진행률(금액) · 파레토 곡선 · 이유·예산·지사·상태 거르기.
- 1클릭 처리: **이상 없음(승인)** — 승인 때 실적을 기록, 재분석으로 숫자가 바뀌면 다시 연다 · **사유 칩**(초과/미달/미시행) · **추천 재배정**(전표 글자가 다른 계획 사업과 분명히 더 닮을 때만 — 유사도 0.75·여유 0.15·설비/연도 충돌 차단) · 사업 골라 옮기기 · 덜 집행된 줄로 가져오기 · 3+ 상세로 이동.
- 승인·사유는 숫자를 바꾸지 않아 마감 연도에도 된다. 재배정은 저장만, 결과는 «분석 반영» 뒤(그 전엔 «재배정 대기»).
- 메인 «다음 할 일»은 검토 큐 한 줄(남은 건수·80% 건수·진행률). 단축키 J·K·A·1~5·E.

### 4단계 통계·내보내기
- 과목별 계획 대비 실적, 전년 대비 증감, 실적 양식(xlsx) 내보내기.

### 5단계 표준화·중장기 전망 (기준연도 축)
기준연도(«몇 년에 세운 가정인가»)마다 가정 한 벌을 둔다. 새 기준연도는 직전 벌을 복사해 시작.

| 영역 | 요구사항 |
|---|---|
| 참고 엑셀·대조 | 예산표준화 V3 양식을 올리면 10년 실적·설비별 등급·표준금액을 읽고 표준화 표 **수식을 산정 규칙으로** 바꾼다. 마감 실적·표준금액을 엑셀과 칸별로 대조 |
| 실적 모집단 | 마감 연도 실적 + 참고 엑셀 실적(마감 안 된 연도). 같은 연도는 마감 실적 우선 |
| 정기비용 분리 | 기계장치의 고온부품재생·LTSA·CRI, 정기유지보수의 LTSA 를 표준화에서 뺀다(사업명 판정 + 사람 수정) |
| 표준금액 | 지사 × 과목 × 등급. 우선순위 수동수정 > 산정 규칙 > 사용자지정 방식 > 자동추천. 규칙 방식: 최근실적·N개년 평균·등급별 평균/최근실적·지정연도 평균·최대값·예산 대체·등급 차용·직접 입력 + 보정률·조정액. 결과마다 «근거» |
| 정비등급 | 설비별(#1 GT·ST·DH…) 이력 + 대표 등급, 미래 정기점검 일정 |
| 구조 변화 | 지사 연혁(연도별 그룹), «실적사용시작»(그 이전 실적 제외) |
| 학습 기간 | 규칙 없는 칸이 쓰는 최근 N개년(기본 3) — 백테스트로 고른다 |
| 전망(10개년) | 기준연도 = 계획본 + 본사 배분, 이후 = 표준금액 × 팩터(손익·자본 구분). 고온부품 계획 · LTSA 정기계약 · CRI 자동 발생(MI + 지급시차) · A급정비 일정(MI·A 전환 해에만) · 투자계획 · 본사 임시사업 · 지사 돌발사업 |
| 보기 | 10개년 표 + 예측 범위, CRI 일정, 한눈에 보기(히트맵 → 연도 구성 → 과목 추이, 발표 모드), 메인 화면 전망 패널 |
| 내보내기 | 표준화 양식(25시트)·중장기 예산 양식, 기준연도로 재기준화 |

## 5. 비기능 요구사항

- **단위**: 화면 천원, 연계 파일 원. 금액은 천원 정수로 비교한다.
- **보안**: 공용 비밀번호 + 작업자 이름, 모든 쓰기 감사 로그, 보안 헤더, 입력값(연도·예산구분) 입구 검증. 실데이터는 팀원 한정.
- **성능**: 화면 구역 API 동시 4개, 계산 결과 캐시(감사 로그 id 기준). DB 왕복이 병목(앱 싱가포르 ↔ DB 서울).
- **운영**: Render(Docker) + Supabase PostgreSQL, main 병합 = 자동 배포, CI = 화면 빌드 → pytest. 주간 DB 백업. 사내 이관 패키지(`deploy/onprem`).
- **화면 원칙**: 설명문 대신 숫자·상태 줄, «? 도움말», 한난 디자인 토큰(대비 AA), 탭으로 한 묶음씩.

## 6. 범위 밖 / 알려진 한계

- 정기비용 판정은 사업명 키워드 기반 — 이름에 표시가 없는 사업은 사람이 고친다.
- LTSA 계약 초안은 «최근 실적 유지» 가정, CRI 짝·시차는 표준화방향 메모와 실적 1건에서 추정.
- ERP 원본에 없는 계정은 분석할 수 없다 — 2023(·2024) 원본에 «외주비-열원정기점검»(A급 정비)이 없다.
- 회계 처리상 같은 해 안에 짝이 없는 음수(전년 비용 역인식·부품 환입·계정대체·환급)는 사업 실적이 음수로 남는다.
- 표준금액 계층적 후퇴(표본이 적은 지사)는 동료 합의 후 별도.
