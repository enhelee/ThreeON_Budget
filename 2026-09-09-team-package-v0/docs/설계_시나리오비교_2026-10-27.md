# 전망 시나리오 비교 (C) — 2026-10-27

> 경진대회 전략 C. 10개년 전망을 가정 2~3벌로 나란히 놓는다(Pigment 식 side-by-side).
> 코드 `pipeline_forecast.run_scenarios` · API `GET /api/forecast/scenarios` · 화면 5번 › «시나리오 비교»(`#/forecast/scenario`, `views/forecast_scenario.js`).

## 1. 왜

전망이 가정 한 벌로만 보이면 «전망을 믿을 수 있나»에 대한 답이 백테스트 오차(과목 25~36%)뿐이다. 가정을 바꿔 나란히 보이면 질문이 **«어떤 가정이 얼마를 움직이나»**로 바뀐다. 정확도 대신 의사결정 범위로 답하는 것이다.

## 2. 손잡이 (저장된 가정 위에 얹기만 — 가정은 바뀌지 않는다)

| 손잡이 | 뜻 | 계산 |
|---|---|---|
| 물가 (연 %p) | 저장된 팩터에 더하는 연 물가 | 활성 팩터는 그대로 두고 «시나리오 물가 조정»(적용구분 전체) 팩터를 하나 더 건다. 배수 = (1+기존)(1+가감)^n — 손익·자본 팩터가 나뉘어 있어도 같은 폭으로 움직인다 |
| 물량 (%) | 정비 범위·물량 증감 | 표준금액(표준화 대상 과목)과 A급정비 1회 금액 × (1 + %/100). 기준연도 계획본·정기계약·고온부품·본사배분·투자계획처럼 «정해진 금액»은 건드리지 않는다 |

- 범위 물가 ±10%p · 물량 ±50%(밖은 잘라 계산). 시나리오 최대 3개, 첫 시나리오가 비교 기준.
- 기본 셋: 기준(±0) · 보수(물가 +1%p, 물량 +10%) · 절감(물가 −0.5%p, 물량 −10%). 화면에서 이름·값을 고쳐 «다시 계산».
- «A급정비 1년 연기»·«고온부품 계획 변경» 손잡이는 넣지 않았다 — 운영 데이터에 미래 정비 일정·고온부품 계획이 아직 없어 숫자가 움직이지 않는다(일정이 들어오면 같은 방식으로 추가).

## 3. 화면

1. 손잡이 카드 3장(계열 색 띠) + «다시 계산»
2. 10년 누계 카드 — 기준 대비 ±억 원(%)
3. 근거 문장 — «보수(기준보다 물가 +1%p · 물량 +10%) → 10년 누계 +2,029억 원(+14.6%), 차이가 가장 큰 지사는 화성지사(+413억 원).»
4. 연도별 전사 합계 선 그래프 — 계열 3색(dataviz 기준 팔레트 앞 세 칸, 색약 검증 통과) · 선 끝 이름표 · 회색 띠 = 기준 시나리오의 예측 범위(전망 표 «예측 범위»를 전사로 더한 것: 표준화 과목 칸만 학습 기간 실적 최소~최대 × 팩터) · 연도마다 마우스 툴팁
5. 지사 × 연도 차이 히트맵 — «고른 시나리오 − 기준» 억 원, 색은 기준 대비 %(파랑 감소 ↔ 회색 ↔ 빨강 증가, 중장기 한눈에 보기와 같은 색), 10년 차이 큰 지사부터

## 4. 성능

입력(DB)은 한 번 읽고 계산만 시나리오 수만큼 — 로컬 사본 3벌 17.8초(전망 표 1벌 15.2초). 결과는 계산 캐시(손잡이 값이 키). 운영 예열이 기본 셋을 미리 계산한다. GET 이라 감사 로그·데이터 버전을 건드리지 않는다.
