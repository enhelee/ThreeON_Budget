# 팀원 실행 가이드 (2026-09-15 · rev17)

## 1. 주소는 하나입니다

**https://threeon-budget.onrender.com**

열면 로그인 화면이 뜹니다. **작업자 이름 + 팀 공용 비밀번호**를 넣고 들어가면, 왼쪽 메뉴로 1~5단계와 설정을 오갑니다. 브라우저 기본인증 팝업은 더 이상 없습니다 — 로그인은 한 번뿐입니다.

예전에 `/app/`이나 `/forecast`를 즐겨찾기에 넣어 두셨다면 그대로 두셔도 됩니다. 자동으로 위 주소로 넘어갑니다.

### 화면마다 주소가 있습니다

새로고침해도 보던 화면이 유지되고, 뒤로가기가 앱 안에서 동작하며, 특정 화면을 링크로 보낼 수 있습니다.

| 주소 | 화면 |
|---|---|
| `/#/home` | 메인 — 오늘 기준 현황과 다음 할 일 |
| `/#/plan` · `/#/collect` | 1 예산 계획 · 2 실적 집계 |
| `/#/branches` · `/#/detail` | 3 실적 분석 · 3+ 상세 |
| `/#/detail/평택지사` | 특정 지사의 상세 — 이 주소를 그대로 공유하면 상대도 같은 화면을 봅니다 |
| `/#/stats` | 4 통계·내보내기 |
| `/#/forecast` | 5 중장기 예측 — 전망 앱이 화면 안에서 열립니다 |
| `/#/settings` | 설정 |

## 2. 일상 작업 순서

1. **1·2단계** — 연도 선택 → 계획본(양식1(월별))·zrfm2 업로드 → `분석 실행`
2. **3+ 상세** — 재배정·✎수정·삭제·추가 → `분석 반영 (N)`
3. **설정** — `AI 학습` → 검토가 끝나면 `연도 마감`
4. **4 통계·내보내기** — 「팀 연계 → 결과 JSON」 다운로드
5. **5 중장기 예측** — 그 JSON을 「예산 실적 집계 → 사업 실적 연결」에 업로드 → 「예산 표준화」·「중장기 예산」에서 계산·엑셀 내보내기

메인 화면의 **다음 할 일**이 지금 무엇을 해야 하는지 알려줍니다 — 미반영 변경, 미배정 전표, 학습 대기, 미마감 연도.

## 3. 로그인·이력

- 로그인 때 입력한 **작업자 이름**이 모든 변경(재배정·수정·삭제·추가·분석·학습·마감)에 기록됩니다 → 설정 탭 「변경 이력」. 실명이나 팀 내 고정 별명을 쓰세요.
- 비밀번호는 관리자가 Render 환경변수에서 확인·교체합니다.

## 4. 자주 묻는 것

**"주소가 안 열려요 / 아주 느려요"**
무료 플랜이라 15분간 아무도 안 쓰면 잠듭니다. 첫 접속에 **50초 이상** 걸릴 수 있습니다. 팀 회의 전에 아무나 한 번 열어 깨워 두면 편합니다.

**"화면이 예전 그대로예요"**
`Ctrl+Shift+R`(강력 새로고침)을 한 번 눌러 보세요. 2026-09-15 이후로는 이 문제가 없어야 정상이니, 그래도 그러면 알려 주세요.

**"5번 탭에 전망 앱이 안 떠요"**
전망 앱이 기동 중일 수 있습니다. 안내 문구의 「새 탭에서 전망 앱 열기」로 확인해 보세요.

**"전망 앱에 저장해 둔 값이 사라졌어요"**
⚠ **현재 알려진 제약입니다.** Render 무료 플랜에는 영구 디스크가 없어서, **배포할 때마다 전망 앱의 팩터·고온부품 계획·본사 마스터 등이 초기화됩니다.** 중요한 설정은 엑셀로 내려받아 따로 보관하세요. 사내 서버로 옮기면 없어지는 문제이고, 근본 해결은 전망 기능을 본 앱으로 흡수하는 작업(Phase 6)에서 이뤄집니다.

**"분석 후 첫 다운로드가 느려요"**
산출물은 분석 때 만들지 않고 첫 다운로드에서 생성합니다(20~30초). 두 번째부터는 즉시입니다.

**"v2에 올린 JSON이 거부돼요"**
연도가 다르거나 여러 연도가 섞인 파일입니다. 해당 연도로 다시 내보내세요. 미배정은 0이어야 정상입니다.

**"표준화에 금액이 빠져요"**
과목·지사를 선택 해제한 상태로 내보내면 미반영분이 '제외'로 갑니다. 구성을 전체 선택 후 다시 내보내세요.

## 5. 각자 PC에서 실행 (서버 없이)

1. Python 3.12~3.14 설치(PATH 체크)
2. 처음 한 번 `app/.env` 만들기 — `.env.example`을 복사해 `APP_PASSWORD`, `SECRET_KEY`를 채웁니다. 비우면 로그인 없이 열립니다(개인 PC 전용)
3. 프론트 빌드가 필요합니다: `cd app/web && npm install && npm run build`
4. `cd app && py -m uvicorn server:app --port 8010` → http://localhost:8010
5. 데이터는 각자 PC에만 생깁니다(`app/data/budget.db`). **Git에 올리지 않습니다**

## 6. 사내 서버

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

볼륨을 쓰므로 데이터가 영속입니다. 자세한 것은 [배포가이드](배포가이드.md) §3.

## 7. 테스트 (개발자)

```bash
cd app && py -m pytest -q
```
