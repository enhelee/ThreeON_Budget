# 팀원 실행 가이드 (2026-10-28 현행)

> 30분짜리 요약과 화면 캡처는 [팀공유_최종안내.html](팀공유_최종안내.html) 을 브라우저로 여세요. 이 문서는 «손에 쥐고 쓰는» 순서만 적습니다.

## 1. 주소는 하나입니다

**https://threeon-budget.onrender.com**

열면 로그인 화면이 뜹니다. **작업자 이름 + 팀 공용 비밀번호**를 넣고 들어가면 왼쪽 메뉴로 1~5단계와 설정을 오갑니다. 로그인은 한 번뿐이고, 3·4단계(표준화·중장기 전망)도 같은 화면 안(5번 탭)입니다 — 별도 프로그램이나 파일 이동이 없습니다.

예전 `/app/`·`/forecast` 즐겨찾기는 그대로 두셔도 됩니다(자동으로 위 주소로 넘어옵니다).

> **2026-09-21 화면이 바뀌었습니다.** 색·글꼴·버튼 모양을 한국지역난방공사 공식 CI(빨간 포인트·검정 버튼·한난체 제목)로 맞추고, 왼쪽 위에 팀 이름 **ThreeON** 을 붙였습니다. **메뉴·순서·기능은 그대로**입니다. 예전 파란 화면이 보이면 `Ctrl+Shift+R`.

## 2. 한 해를 돌리는 순서

1. **설정 → 연도별 기준정보** — 새 연도의 지사·과목 구성이 맞는지 확인(전년 복사 가능).
2. **1 예산 계획** — 사업별예산 업로드 → 계획본(양식1) 내려받기. 주관부서예산 원본(손익·자본·건설공사)은 **세 파일을 한 번에 같이 골라** 올리면 됩니다.
3. **2 실적 집계** — 계획본 + `zrfm2.XLSX` 업로드 → `분석 실행`(16~19초).
4. **✓ 검토 큐** — 위에서부터 처리합니다. 맞으면 `✓ 이상 없음`, 계획과 다르면 사유 칩(예: «차년도 이월»)을 한 번 누르면 저장, 다른 사업 전표가 섞였으면 `전표·재배정`에서 추천대로(또는 사업을 골라) 옮깁니다. 위 요약 줄(남은 건수·금액·처리)이 바로 바뀝니다. 단축키 J·K 이동 · A 승인 · 1~5 사유 칩 · E 전표. 승인·사유는 마감 연도에도 됩니다(검토 기록으로만 남고 마감 숫자는 그대로). 2 실적 집계의 이상 알림 건수를 누르면 그 이유로 거른 검토 큐가 열립니다.
5. **3+ 상세** — 큐에서 «3+ 상세 →»로 넘어오거나, 지사 카드(정렬: 편차 큰 순·집행률·계획·실적·지사명순)에서 지사를 골라 재배정·✎수정·삭제·추가 → 상단 `분석 반영 (N)`. 메인의 **다음 할 일**이 검토 큐·미배정 전표·미반영 변경을 알려 줍니다.
6. **설정 → AI 학습**(확정 매칭을 학습) → 검토가 끝나면 **연도 마감**. 마감된 연도만 5번 탭의 입력이 됩니다.
7. **4 통계·내보내기** — 손익예산·자본예산 탭에서 실적 집계표(재무팀 양식)·전표+매칭 원장·전표별 매칭 CSV, 전년 대비 증감 탭에서 증감.
8. **5 표준화·중장기 전망** — 기준연도를 고르고(예: 2026) → «기준정보(가정)»:
   - **정비등급** 탭 — 표가 «26~35년 전지사 정비등급» 엑셀과 같은 줄(삼송 #1·#2 GT, 동탄 #1·#2 Block …)입니다. 칸을 고쳐 `저장`하거나 엑셀을 «정비등급 양식에서 가져오기 → 전체 교체». «정비등급 양식으로 내려받기»는 같은 양식(바뀐 칸만 색)
   - **고온부품** 탭 — «26~35년 전지사 고온부품» 양식 그대로 가져오기·내려받기, 표에서 칸 직접 고치기
   - **설비용량·신규표준** 탭 — 설비 현황(MW)과 용량 규칙(양산·대구·청주·수원을 기준 5개 지사 규칙으로), 규칙 수치·오차
   - 표가 길면 오른쪽 위 «접기», 묶음 줄 맨 앞 «펼치기 ▾». 설명은 제목 옆 ⓘ 에 마우스를 올리거나 **예측이**에게 물어보세요(예: «강남지사 열원경상정비 표준금액 근거» → 표 + 엑셀)
   - «표준화»에서 지사·과목·등급·검색으로 거르고 → «중장기 전망»에서 10개년 표(정기유지보수·기계장치 ▾ 세부)·한눈에 보기·양식 내보내기

## 3. 로그인·이력

- 로그인 때 입력한 **작업자 이름**이 모든 변경(재배정·수정·삭제·추가·분석·학습·마감·전망 입력)에 기록됩니다 → 설정 탭 「변경 이력」. 실명이나 팀 내 고정 별명을 쓰세요.
- 비밀번호는 관리자가 Render 환경변수에서 확인·교체합니다. 바꾸면 전원 재로그인.

## 4. 자주 묻는 것

**"주소가 안 열려요 / 아주 느려요"**
무료 플랜이라 15분간 아무도 안 쓰면 잠듭니다. 첫 접속에 **30~60초** 걸릴 수 있습니다. 회의 전에 아무나 한 번 열어 깨워 두세요. (사내 서버로 옮기면 사라지는 문제입니다.)

**"화면이 예전 그대로예요"**
`Ctrl+Shift+R`(강력 새로고침) 한 번. 그래도 그러면 알려 주세요.

**"5번 탭에 표준화 결과가 비어요"**
마감된 연도가 없거나 기준연도를 안 골랐을 때입니다. 설정에서 연도를 마감하고, 5번 탭 상단 기준연도를 확인하세요.

**"전망 값이 지사마다 0 이에요"**
정비등급 이력을 아직 안 넣은 지사는 «표준» 등급으로 계산됩니다. «기준정보(가정) → 정비등급 이력» 양식을 채워 올리세요.

**"분석 후 첫 다운로드가 느려요"**
산출물은 첫 다운로드에서 생성합니다(20~30초). 두 번째부터는 즉시.

**"배포하면 입력한 팩터·고온부품이 사라지나요"**
아니요. Phase 6 이후 전망 입력은 전부 DB 에 있어 배포·재시작에도 남습니다(기준연도별로 한 벌).

## 5. 각자 PC에서 실행 (서버 없이)

1. Python 3.12~3.14 설치(PATH 체크), Node 20+ (프론트 빌드용)
2. `.env.example` 을 `app/.env` 로 복사해 `APP_PASSWORD`·`SECRET_KEY` 를 채웁니다. 비우면 로그인 없이 열립니다(개인 PC 전용)
3. `cd app/web && npm install && npm run build`
4. `cd app && py -m uvicorn server:app --port 8010` → http://localhost:8010
5. 데이터는 각자 PC에만 생깁니다(`app/data/budget.db`). **Git에 올리지 않습니다**

## 6. 사내 서버

인터넷이 없는 서버에 이미지 파일 하나와 `.env` 하나로 올립니다. 절차와 스크립트(`deploy/onprem/`)는 [사내이관_가이드](사내이관_가이드.md). 볼륨을 쓰므로 데이터가 영속입니다.
