**정비등급과 물량은 예산 시스템 안에서 만들 수 없습니다.** 두 값은 모두 설비 쪽 자산이며, 바탕화면의 **ThreeON Maintenance(유지보수 일정 알리미)** 에 이미 존재합니다.

| 입력 | 경로 | 비고 |
|---|---|---|

### 2.2 출력 스키마 확정안

연계규격 §2.6의 제안(`지사, 정비등급, 투자유형, 예산과목, 표준금액(천원), 표본수, 산출근거연도`)에 **3개 컬럼을 추가**합니다. 표본이 얇다는 사실을 소비 측이 알 수 있어야 하기 때문입니다.

`budget_benchmark.csv` (utf-8-sig, 금액 천원)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `지사` | str | 정규화된 처지사 |
| `지사그룹` | str | 본사 / 중대형CHP / 소형CHP / DH |
| `정비등급` | str | CMMS 등급 |
| `투자유형` | str | 손익 / 자본 |
| `예산과목` | str | 정규화 과목(`과목정규`) |
| `표준금액` | float | **설비 1기·1년당 정비비(천원)** — §2.3 정의 |
| `표본수` | int | 산출에 쓰인 (설비 × 연도) 표본 개수 |
| `산출근거연도` | str | `"2023,2025"` 형식 |
| **`산출수준`** | str | `실측` \| `지사그룹대체` \| `전사대체` — §2.4 후퇴 단계 |
| **`분산지표`** | float\|None | 표본 MAD ÷ 표준금액. 신뢰도 지표 |
| **`제외금액`** | float | 이상치·미반영으로 모집단에서 빠진 금액 |

### 2.3 표준금액의 정의 — 분모를 먼저 정한다

"표준금액"은 분모 없이는 정의되지 않습니다. 이 설계는 **설비 1기당 연간 정비비(천원/기·년)** 로 둡니다.

```
표준금액[지사, 등급, 유형, 과목]
    = median( 전표합계[설비, 연도] / 1 )   over (설비 × 마감연도) 표본
```

- **중위수(median)** 를 씁니다. 평균은 대수리 1건에 끌려갑니다.
- 이상치는 **MAD 기준 ±3σ 상당**에서 절사하고, 절사된 금액을 `제외금액`에 기록합니다(버리지 않고 추적).
- 용량(MW) 기준 단가가 필요하면 분모만 교체할 수 있게 `denominator` 파라미터로 뺍니다. **분모 정의를 바꾸면 벤치마크 전체가 재산출되므로 계약 변경 취급**합니다.

### 2.4 얇은 표본 대응 — 계층적 후퇴

마감 연도가 2개뿐이므로 (지사 × 등급 × 과목) 조합 대부분은 표본이 1~2개입니다. 표본이 적은 칸을 그대로 내보내면 4단계가 잡음을 증폭합니다.

```
표본수 >= 3  ->  실측         (해당 칸 median)
표본수 1~2   ->  지사그룹대체  (같은 지사그룹 × 등급 × 과목의 median)
표본수 0     ->  전사대체      (전사 × 등급 × 과목의 median)
그래도 0     ->  행을 만들지 않음 (4단계가 결측으로 인지)
```

`산출수준` 컬럼이 어느 단계에서 나온 값인지 항상 밝힙니다. **없는 값을 0으로 채우지 않습니다** — 연계규격 §1의 "결측은 None 유지" 규약과 동일한 이유입니다.

### 2.5 불변식 검증 (회귀 기준)

2단계가 이미 쓰고 있는 총액 보존 불변식을 3단계도 승계합니다.

```
Σ 모집단 전표금액
  = Σ (표준금액 × 표본수)   ± 절사 제외금액
  ≤ 실적본 종합표 총액
```

23년 수기 분석본(손익 −0.06% 검증본)이 있으므로, **23년만으로 산출한 벤치마크로 23년 실적을 역산**했을 때 지사별 오차가 임계 안에 드는지가 3단계의 회귀 테스트입니다.

## 3. 4단계 — 중장기 소요 전망

### 3.1 계산식

연도 `y`, 설비 `e`에 대해:

```
소요[e, y] = 표준금액[지사(e), 등급(e), 유형, 과목]
             × 물량계수[e, y]        # 오버홀 주기 도래 (CMMS)
             × 노후계수[e, y]        # 경과연수
             × 물가지수[y]           # 외생 입력
```

연도 합계는 지사·과목 축으로 집계합니다. 축은 3단계와 동일하므로 1·2단계 산출물과 **바로 대조 가능**합니다.

### 3.2 팩터 3종

| 팩터 | 출처 | 기본 규칙 |
|---|---|---|
| **물량계수** | CMMS 오버홀 중장기 매트릭스 | 주기 도래 연도 = 1.0, 비도래 = 경상 수준(0.2~0.3). 대수리비를 도래 연도에 몰지 않으려면 `연분할` 옵션으로 주기 N년에 균등 배분 |
| **노후계수** | 설비 준공연도 (CMMS) | 경과연수 구간별 단조증가 계단함수. 초기 권고 `0~10년:1.0 / 11~20년:1.15 / 21~30년:1.35 / 30년+:1.6` — **실적으로 보정해야 하는 가정값** |
| **물가지수** | 외생 (건설공사비지수·소비자물가 등) | 연도별 배열을 설정 파일로 주입. 산출물에 사용한 지수를 그대로 기록 |

물량계수가 설계의 핵심입니다. 나머지 둘은 완만한 곱셈 보정이지만, 물량계수만이 **연도 간 큰 차이**를 만듭니다.

### 3.3 출력 스키마

`forecast_{from}_{to}.csv` (utf-8-sig, 천원)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `연도` | str | 4자리 |
| `지사` / `지사그룹` | str | 3단계와 동일 축 |
| `투자유형` / `예산과목` | str | 3단계와 동일 축 |
| `소요금액` | float | 천원 |
| `시나리오` | str | `기준` \| `보수` \| `적극` |
| **`근거유형`** | str | `실적벤치마크` \| `계획추세` \| `물량직산` — §3.5 |
| **`산출수준`** | str | 벤치마크에서 승계 (`실측`/`지사그룹대체`/`전사대체`) |
| `팩터셋ID` | str | 재현용. 사용한 물가·노후·물량 설정의 해시 |

`팩터셋ID`가 있어야 "작년 전망은 왜 달랐나"에 답할 수 있습니다. 2단계가 `run`으로 재현성을 확보한 것과 같은 장치입니다.

### 3.4 시나리오

물가지수와 물량계수만 흔듭니다. 표준금액(실적 기반)은 고정합니다 — 실적을 흔들면 근거가 사라집니다.

| 시나리오 | 물가 | 물량 |
|---|---|---|
| 기준 | 지수 그대로 | 주기 그대로 |
| 보수 | +1.5%p | 도래 연도 +1년 지연 |
| 적극 | −1.0%p | 주기 단축(예지보수 반영) |

### 3.5 베이스라인이 없는 과목 처리

자본 건설공사 3과목(외주비-열원공사비 · 재료비-열원자재비 · 외주비-열원기술용역비)은 ERP에 계정이 없어 실적 벤치마크를 만들 수 없습니다. **이 과목을 0으로 두면 전망이 과소 추정됩니다.**

- `근거유형 = 계획추세` — 1단계 계획본(`plan_row`)의 연도별 추세로 산출
- 별도 물량 소스가 확보되면 `물량직산`으로 전환
- 어느 쪽이든 `근거유형` 컬럼으로 구분되므로, 보고 시 "실적 근거"와 "계획 근거"를 섞어 말하지 않을 수 있습니다

## 6. 착수 전 확정할 것

### 6.1 정비등급 마스터의 조인 키 (**차단 사항**)

연계규격 §2.7이 미정으로 남겨둔 항목입니다. 예산 축은 **처지사 × 예산과목**이고 CMMS 축은 **설비ID**입니다. 둘을 잇는 중간 키가 필요합니다.

- 후보 A: 사업장코드 → 처지사 (다대일). 구현은 쉽지만 설비 단위 해상도를 잃음
- 후보 B: 설비ID → 사업장코드 → 처지사 (CMMS 설비 대장 경유). 해상도 유지, 매핑 테이블 필요

§2.3의 표준금액이 **설비 1기당**으로 정의되므로 **후보 B가 필요**합니다. 후보 A로 가면 분모를 지사 단위로 바꿔야 하고, 그 경우 정비등급 축의 의미가 대부분 사라집니다. 이 결정을 먼저 내려야 2번부터가 진행됩니다.

### 6.2 CMMS 연동 방식

ThreeON Maintenance는 이미 REST API와 토큰 인증을 갖추고 있어 연동 자체는 어렵지 않습니다. 다만 예산 시스템이 **오프라인 분리망 전용**이라는 보안 설계가 있으므로, 실시간 API 호출이 아니라 **CSV 추출 → 수동 반입**이 기본이어야 합니다.

- 추출 대상: 설비 대장(등급·준공연도·사업장), 오버홀 중장기 매트릭스
- 반입 계약: `maintenance_grade_master.csv`, `overhaul_matrix.csv` (스키마는 §6.1 결정 후 확정)

### 6.3 표본 부족을 어디까지 감수할지

마감 연도 2개는 10개년 추세 추정에 충분하지 않습니다. 이 설계는 **추세를 실적에서 뽑지 않고 팩터로 외생 주입**하는 방식으로 이 한계를 우회했습니다(§3.1). 그래도 남는 사실은 다음과 같습니다.

- 표준금액의 수준(level)은 2개년 실적에 근거 — 신뢰 가능
- 연도 간 변화(shape)는 **CMMS 물량 + 가정된 노후계수**에 근거 — 검증되지 않은 가정
- 노후계수 기본값(§3.2)은 **실적이 3~4개년 쌓이면 반드시 재추정**해야 합니다

보고 시 이 구분을 흐리지 않는 것이 중요합니다. "실적 기반 전망"이라고 말할 수 있는 부분은 수준이고, 파동은 아직 가정입니다.
