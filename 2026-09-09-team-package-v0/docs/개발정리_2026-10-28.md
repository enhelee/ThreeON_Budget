## 3. 함정 (몸으로 배운 것)

- **Git Bash 긴 heredoc**(따옴표·백틱 많음)은 «unexpected EOF» 로 깨진다 → 편집 스크립트는 Write 로 파일을 만들어 `py 파일` 로 돌린다.
- `data-fcgroup` 처럼 **같은 data- 속성 이름을 클릭·변경 둘에 쓰면** 선택 상자를 누를 때 클릭 처리기가 먼저 탄다 — 새 단추는 새 이름(`data-fcdgrp`·`data-fcgrp`·`data-fcbopen`·`data-fcpanel`).
- 표 맨 오른쪽 칸에 둔 단추는 표가 가로로 넘치면 화면 밖 — 단추는 줄 맨 앞 + `sticky left-*`.
- 용량 모형에 «건설중인자산-재생고온부품»을 넣으면 그 몫이 전망 표에 안 나타난다(그 줄은 고온부품 계획에서 온다) — 모형 과목 = 전망 표가 표준금액으로 채우는 과목(`capacity.MODEL_ACCOUNTS`).
- 정비등급 양식 레이아웃은 **비우기 전에** 읽는다 — 빈 줄은 `grade_plan_layout` 에서 빠진다(`grade_plan_from_cells` 처음 버그).
- **Aside** 파일 올리기는 Aside 세션 폴더(`~/.aside/u/0/sessions/<세션>/…`) 안 파일만 된다 — 그리로 복사해 `filechooser.setFiles`. Aside 탭에서 해시만 바꾸면 새 번들을 안 받는다 → `/?r=<시각>#/…`. 배경 탭은 스크린샷이 시간 초과 → `bringToFront()`. 운영 쓰기는 사용자가 Aside 에서 로그인한 세션으로만.
- 백테스트 «지금 설정» 표시는 화면에서 고른 학습 기간 기준(재학습 전에도 맞게).
