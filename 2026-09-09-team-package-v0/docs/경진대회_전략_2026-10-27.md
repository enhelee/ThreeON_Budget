## 1. 현재 앱의 핵심 가치 요약
- **해결하는 문제**: 발전플랜트 유지보수 예산의 «계획(엑셀) ↔ 실적(SAP 전표)» 수작업 대조(담당자 1인 약 3개월)와, 그 결과로만 만들 수 있는 10개년 전망이 끊어져 있던 것. 계획→실적 집계·AI 매칭→검토·마감→통계→표준화·전망 5단계를 한 앱에서 끝낸다.
- **핵심 사용자**: 플랜트기술처 예산 담당(업로드·검토·마감·전망), 19개 지사 담당(집행률·차이 사유), 재무·경영 보고(양식 xlsx·발표 모드).
- **지금 가장 강한 장점(실측)**
  - 실데이터 3개년(’23·’24·’25) 전 과정 운영·마감 완료, 미배정 전표 0건, 총액 보존 검증(유실 0원).
  - 사람이 확정한 판단이 학습표(13,271건, 사람 확정 668건)로 쌓여 이듬해 자동 매칭에 재사용되는 Human-in-the-loop.
  - 외부 AI 호출 없음(폐쇄망 이관 가능) + 감사 로그·연도 잠금·전표 드릴다운·매칭 근거 — 공공기관이 요구하는 «설명 가능·보안» 구조.
  - 자동 테스트 335건·CI·자동 배포, 화면 전환 2.4~5.3초.
  - 5단계 «한눈에 보기»(히트맵→연도 구성→과목 추이, 발표 모드)는 데모용 시각 자산.

## 2. 시장·경쟁 서비스 분석

|---|---|---|

| ③ 기획예산처 AI-ON «AI 예산 어시스턴트»(LLM, ’27 가동) | 우리는 전표 1건 단위 귀속·총액 보존·전망까지 «숫자가 맞는» 시스템 | 자연어 질의·요약 같은 «생성형 AI 체감»이 없음 |
| ④ 더존 ONE AI PE·Amaranth10(공공 폐쇄망 AI) | 범용 결재·행정 AI. 예산 매칭·표준금액·10개년 전망 전용 로직 없음 | 브랜드·보안 인증(N2SF) 신뢰도 |
| ⑤ FP&A SaaS(Datarails·Vena·Pigment·Anaplan) | 영문·클라우드·고가. 한글 전표 텍스트 매칭·정비등급 표준금액 없음 | **차이 설명(variance commentary) 자동 초안, 시나리오 side-by-side 비교**가 업계 표준 기능 — 우리에게 없음 |
| ⑥ Ramp Accounting Agent(참고 UX) | — | «Ready to sync / Needs review / 저확신 노랑 + 누가 왜 코딩했는지 hover», 수정이 다음 코딩에 반영 — 우리 3+ 화면의 검토 UX가 이 수준에 못 미침 |
| ⑦ IBM Maximo AIP·Copperleaf(자산투자계획) | 설비 수명주기 기반 장기 투자 최적화. 우리는 실적 기반 표준금액 | «설비 등급·정기점검 일정»을 이미 갖고 있어 확장 여지 있음 |

**사용자가 실제로 불편한 지점(시장 공통)**: FP&A 시간의 46%가 «데이터 모으고 맞추기»(FP&A Trends 2025). AI 분류 도구에서도 «중간 확신도(70~95%) 구간이 60%»라 결국 전부 다시 본다는 불만(실무자 사례). → **«어디부터 볼지»를 금액·위험 가중으로 골라주는 검토 큐와, «왜 이 숫자인지» 한 문단 설명이 사용자가 진짜 원하는 것.**

## 4. 심사위원 관점의 냉정한 평가
- **왜 이 앱이어야 하는가**: «이미 3개년 실데이터로 운영·마감된 유일한 사내 시스템. 사람의 판단이 근거와 함께 쌓여 매년 자동화율이 올라가고, 같은 숫자로 10개년 전망까지 이어진다. 외부 AI 없이 폐쇄망에서 돈다.»
- **예상 질문과 약한 답변**
  1. «AI라기보다 규칙·유사도 아닌가?» → 현재 답은 4층 구조 설명뿐. **근거 설명 자동 초안(B)**과 학습 전후 자동확정률 변화 숫자로 보강.
  2. «전표 단위 정확도는?» → 미측정. **E**로 숫자 확보.
  3. «10개년 전망 오차 25~36%면 쓸 수 있나?» → **C**: 범위·시나리오로 답. «표본 2개년 → 누적될수록 좁아진다» 로드맵.
  4. «3개월→20초는 과장» → «자동 분석 20초 + 검토 N일(’26년 실측 예정)»로 정직하게.
  5. «SAP 직접 연동은?» → 파일 업로드가 정보화부서 협의 없이 «즉시 적용» 가능한 이유로 뒤집기. 연동은 ’27 계획.
  6. «실데이터를 외부 클라우드에?» → 검토 기간 한정, 사내 이관 패키지(Docker) 준비, 발표는 더미 데이터.
  7. «다른 처·지사 예산으로 확장?» → 기준정보(지사·과목·별칭)가 설정 화면에서 바뀌는 구조 시연.
- **경쟁작에 질 수 있는 이유**: 생성형 AI 데모(챗봇·요약)가 주는 «와» 체감 부족, 화면이 «대시보드»로 보여 독창성 점수 약함, 알림·미입력 건수가 미완성 인상.
- **뒤집기 전략**: «설명 가능한 AI + 학습 순환 + 전망 시나리오»를 한 흐름으로 묶어 «재배정 한 번에 집행률·알림·근거·전망이 연쇄로 바뀌는» 장면을 보여준다. 생성형 AI 경쟁작은 «숫자가 맞는지» 증명 못 하지만 우리는 총액 보존 0원·수기 대비 −0.06%를 보여준다.

## 5. 우승 가능성을 높이는 핵심 기능 제안
- **반드시 구현(3개)**: ① 검토 큐(A) ② 근거 설명 자동 초안(B) ③ 전망 시나리오 비교(C)
- **있으면 강력하지만 우선순위 낮음**: Cmd+K·단축키, 지사 현황판, 변경 이력 타임라인, sLLM 질의(폐쇄망, ’27).
- **데모에서 반드시 보여줄 흐름**: 업로드→20초 분석(총액 보존 0원) → 검토 큐 상위 1건 재배정(근거 설명·알림·집행률 즉시 갱신, 학습 대기 +1) → 마감 → 한눈에 보기 히트맵 줌 → 시나리오 비교(물가 +1%p = 10년 누계 +N억) → 양식 내보내기·감사 로그 한 장.
- **3분 발표의 가장 인상적인 장면**: 재배정 1클릭 후 화면 전체 숫자가 연쇄로 바뀌는 «살아 있는 장부» + 시나리오 차이 히트맵.
