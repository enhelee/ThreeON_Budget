# 사업매칭 도구 — grace 최신본 (matching_tool_grace)

담당: grace(사업매칭). 기존 파일을 건드리지 않고 개선한 매칭 도구를 따로 담았습니다.
앱 임베드 매칭도구(`matching_tool_src/`)의 **정확도 개선판**입니다.

## 어떻게 수정했는지 = 커밋 이력을 보세요
이 폴더의 **커밋 하나하나가 grace가 프로그램을 실제로 고친 과정**입니다(오래된 것 → 최신).
각 커밋의 diff를 열면 어느 로직을 어떻게 바꿨는지 그대로 보입니다. 예:
- `netting 핵심 로직 …` → `지사 간 매칭 차단` → `IDF 가중` → `금액매칭 전 과목 확대`
- `크리티칼 지사합산` → `경영지원처 본사사옥 제외` → `정기점검 총액배분` → `보정 코드 내장`

## 핵심
- **raw + 예산계획만으로 답 산출** (실적/채점표 불필요)
- 손익 미배분 **45.5% → 0.2%**, 예측모드 사업배정 **99.8%**
- 담당자 확정 보정 70건 **코드 내장**(`src/corrections.js`) → 보정사전 파일 불필요
- `matched_{연도}.csv` 내보내기 · 단위테스트 58/0

## 빌드 / 테스트
```sh
node build.mjs        # src/* 인라인 → 예산실적정리.html
node test/unit.mjs    # 58 통과
```

## 앱 연동 (리더 확인 요청)
예측 결과를 (A) `classified_{연도}.csv` / (B) 결과 JSON(미배분0 강제) 중
어느 문으로 연결할지 정해주시면 해당 출력 형식을 추가하겠습니다.
임베드 교체 시 기존 `matching_tool_src` 자리에 이 폴더 산출물을 넣으면 됩니다.
