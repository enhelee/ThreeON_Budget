# ThreeON 팀 공유판 · 2026-09-08 v2

기존 같은 날짜 폴더와 구분하기 위한 두 번째 배포본입니다. IBM Carbon 참고 디자인과 사업별 실적 매칭 → 표준화 → 중장기 예산 연결을 포함합니다. 이 폴더만 복사해도 실행할 수 있습니다.

## 실행
1. Python 3.12를 설치하세요. Windows에서는 Python 설치 시 PATH 옵션을 선택하세요.
2. Windows: `실행_Windows.bat`를 더블클릭합니다.
3. Mac: 터미널에서 이 폴더로 이동해 `bash 실행_Mac.command`를 실행합니다.
4. 브라우저에서 http://127.0.0.1:8501 로 접속하세요. 설치에는 인터넷이 필요하며, 종료는 터미널에서 Ctrl+C입니다.

직접 실행하려면 가상환경을 만든 뒤 `python -m pip install -r requirements.txt`, `python run_budget.py` 순서로 실행하세요. 이후에는 가상환경의 Python으로 `run_budget.py`만 실행해도 됩니다.

## 검토 자료 연결
공개 배포본에는 실제 전표, 보정사전, 연결 결과가 포함되지 않습니다. 담당자에게 결과 JSON을 별도로 받아 **예산 실적 집계 → 사업 실적 연결**에서 올리고 **배정분을 표준화·중장기 예산에 연결**을 누르세요.

처음부터 매칭하려면 같은 화면의 매칭 도구에 RAW, 양식2·양식3 집계표, 보정사전을 올린 뒤 팀 점검용 결과 JSON을 생성하세요. 예산 표준화·중장기 예산 예측에서 **연결한 사업 실적**을 선택합니다. 예측에는 정비등급 이력 등 별도 업무 자료가 필요합니다. 미배정분이 남은 중간 점검용 결과이며 전체 실적 확정값이 아닙니다.

개인 저장 데이터는 이 폴더 안에 보관됩니다. 기존 버전의 데이터가 자동 이동되지는 않습니다. 기존 폴더를 덮어쓰지 말고 결과 JSON으로 연결하세요.
