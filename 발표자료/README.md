# ONDO 발표자료 (11/4 해커톤)

ThreeON 3조 발표 덱입니다. 32장, 영상 클립 포함.
공유 링크(claude.ai)에 올라가 있는 최신본과 같은 파일입니다.

## 가장 쉬운 방법 — html 한 파일

`ONDO_발표자료_한파일.html` (약 59MB) 하나만 다른 컴퓨터로 옮겨 **크롬·엣지에서 더블클릭**하면 됩니다.
영상·글꼴·그림이 모두 파일 안에 들어 있어 인터넷 없이도 열립니다. 처음 열 때 5~10초 걸릴 수 있어요.
GitHub 화면에서는 너무 커서 미리보기가 안 되니 **Download raw file** 로 받으세요.

덱을 고친 뒤 다시 만들기:

```bash
python3 한파일_만들기/bundle_deck.py . ONDO_발표자료_한파일.html 한파일_만들기/vendor
```

## 폴더째 여는 법

브라우저에서 `index.html`을 바로 더블클릭하면 영상·화면을 못 불러옵니다. 이 폴더에서 작은 웹 서버를 켜고 여세요.

```bash
cd 발표자료
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다.

## 조작

- **→ / 클릭**: 다음 장 · **←**: 이전 장
- **P**: 발표자 창(대본 메모 포함) 열기
- 영상 장은 자동 재생되고, 끝나면 클릭해서 넘어갑니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 덱 본체 (장 순서 · 발표 메모) |
| `composition/index.html` | 각 장 화면 |
| `composition/assets/` | 영상 클립 · 캐릭터 그림 · 글꼴 |
| `player.js`, `slideshow.js` | 덱 재생기 (HyperFrames) |
