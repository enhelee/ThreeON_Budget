배포

지금은 무료로 팀 검토, 최종은 사내 서버

지금 — Render(Docker) + Supabase(PostgreSQL) + GitHub Pages

  • 단일 이미지 → Render Free 웹서비스, HTTPS 자동. 15분 미사용 시 슬립(첫 접속 30~60초)
  • 디스크 비영속 → DB는 Supabase 무료 500MB(영속·백업). DATABASE_URL만 바꾼다
  • 이 소개 페이지는 GitHub Pages(무료·영구). Vercel은 정적 페이지에만 적합 — 서버리스 제한(10~60초, 영속 프로세스 없음)으로 Streamlit·분석 API 부적합
  • 실데이터를 외부 클라우드에 두는 기간은 임시. 사내 규정 확인, 종료 시 Supabase 정리

최종 — 사내 서버(분리망)

  • docker compose up -d 한 줄. 볼륨 budget_data·forecast_data, 선택 --profile pg로 PostgreSQL 컨테이너
  • 인터넷 없는 서버: 인터넷 PC에서 docker save → 반입 → docker load. 이미지 안에 pip·Caddy 전부 포함
  • Docker가 없으면 pip download로 오프라인 설치 후 uvicorn·streamlit 직접 실행
  • 이관 후 Render·Supabase 자원 삭제, 개인 계정 전환 검토
  1. GitHub에 2026-09-09_팀공유(취합본)_v0 업로드 — .gitignore가 .env·DB·CSV를 걸러준다
  2. Supabase 프로젝트 생성 → Transaction pooler 연결문자열 → 로컬 py scripts/db_check.py로 스키마 검증(필요 시 --migrate)
  3. Render Blueprint(render.yaml) 적용 → 환경변수 APP_PASSWORD·DATABASE_URL 입력 → 빌드 5~8분 → /healthz
  4. 팀에 주소·비밀번호(비밀 메모)·작업자 이름 규칙 공지

학습

모델은 버전으로, 학습데이터는 확정 워크플로로

v2 분류기 3종(전표텍스트→투자유형, 사업명→투자유형, 사업명→투자유형세부)은 파일로만 있어 "누가 무엇으로 학습했는지"가 없었다. 이제 budget_app DB의 model_registry(메타+joblib BLOB+SHA256+활성 플래그)·training_example(입력·라벨·출처·확정·작업자)·training_snapshot(재학습 시점 CSV)이 보관한다.

  1. 데이터 유입 — v2 파일 반입(v2_model_sync.py --push), CSV 가져오기, 자동예측(미확정)
  2. 사람 확정 — 확정 라벨은 자동값이 덮지 못한다. 잘못된 예제는 비활성(삭제 아님)
  3. 수동 재학습 — 관리자 [재학습] 버튼(최소 20건·2유형). 스냅샷 저장 → 학습 → 새 버전 활성. 자동 재학습 없음
  4. 검증·롤백 — CV 정확도·확정비율 확인, 나쁘면 이전 버전 [활성화] 즉시 롤백. 전부 감사로그
  5. v2 반영 — v2_model_sync.py --pull로 활성 버전을 v2 파일명으로 내려받음(동료 코드 무수정)

매칭 학습표(learned_match 10,888건)는 성격이 다른 규칙표라 기존대로 DB에 두고, 실행은 설정 탭 [AI 학습] 1회 원칙을 유지한다.
