## 6. 남은 협의·후속 과제
1. **Python 버전** — v2 `실행_Windows.bat`은 3.12 전용. 이 PC는 3.14만 있어 로컬 bat을 별도 제공. 팀 표준 버전 합의 필요(3.14에서 183 테스트 통과했으므로 3.12 강제는 불필요해 보임).
2. **동료 README 후속 과제** 중 나머지: `project_matching.py` 지사 보존, `plan_vs_actual.py` 지사×과목×사업행 키 집계, `validate_upload.py` 타지사 상쇄 방지 — 동료 코드 몫. 우리 JSON에는 지사·과목·원본행이 이미 들어가 있어 그쪽 개선 시 바로 활용 가능.
3. **표준화 입력의 의미 차이** — v2 「연결한 사업 실적」은 배정분만 사용(미배정·제외 제외). 우리 JSON은 미배정 0이므로 전액이 들어가지만, 미반영(선택 해제)이 있는 run을 내보내면 그 금액은 표준화 입력에서 빠진다 — 내보내기 전 지사·과목 구성을 전체 선택으로 두는 것을 권장.
4. **우리 3·4단계 설계(CMMS 설비단위·중위수·팩터셋)** — 팀 v2 '등급별 평균' 방식의 개선 제안으로 재분류. 정비등급 축은 v2가 `site_year_grade.csv`(재무팀 참고 엑셀 import)로 해결했으므로, CMMS 연동은 다년도 실적이 쌓인 뒤 재검토.
5. 2023 자본 55,820,722 vs 기존 기준치 55,820,726(천원) — 행별 반올림 누적 차이(4천원), 원 단위 JSON이 더 정확.
