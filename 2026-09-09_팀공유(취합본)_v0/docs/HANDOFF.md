## 1. 한눈에

발전플랜트 지사별 유지보수 예산을 **계획 수립 → 실적 자동매칭 → 검토·수정·학습 → 통계/Excel → (예정) 표준화·중장기 예측** 으로 다루는 로컬(오프라인) 웹 시스템.

- **기본 실행**: `budget_app/분석프로그램_실행.bat` 더블클릭 → **http://localhost:8010**
  (수동: `py -m uvicorn server:app --port 8010`)
- **스택**: Python 3.10+ · FastAPI + uvicorn · SQLite(`data/budget.db`) · 웹 SPA(webapp/index.html) · pandas · openpyxl · rapidfuzz
- **테스트**: `budget_app`에서 `py -m pytest -q` → **71 passed** (약 6분)
- Streamlit(app.py)·run.bat·run.sh는 **레거시 UI** — 유지보수하지 않음.

### 검토·수정 기능 (rev13 현재)

**저장 · 분석 · 학습이 분리되어 있습니다** — 수정은 즉시 저장(0.04초)되고, 분석은 모아서 한 번
(헤더 `분석 반영 (N)`, 16~19초), AI 학습은 설정 탭 버튼에서 따로 합니다.
권장 순서: ① 수정·저장 여러 건 → ② 분석 반영 → ③ AI 학습 → ④ 연도 마감.

원자료(`plan_row`/`erp_row`)는 절대 수정하지 않고, **모든 수정을 "지시 테이블"에 기록한 뒤 재분석으로 반영**한다.
따라서 이력을 지우면 언제나 원상복구되고 총액 보존식은 항상 유지된다.

| 하고 싶은 일 | 하는 곳 | 저장되는 곳 |
|---|---|---|
| 전표를 다른 사업/지사로 옮기기 | 상세 → 전표 체크 → 재배정 바 | `override`(+`target_dept`) |
| **사업을 통째로 다른 지사·처로 옮기기** | 상세 → ✎ → **예산귀속 지사** 변경 | `biz_edit.처지사` + `override.target_dept` |
| 사업명·속성·부서명 고치기 | 상세 → ✎ | `biz_edit` (개명 시 재배정·학습 자동 동기화) |
| **연예산(A)·예산과목 고치기** | 상세 → ✎ | `biz_edit.연예산` / `.예산과목` |
| 계획에 없는 사업 추가 | 상세 → ＋사업 추가 | `manual_biz` |
| **사업 삭제 / 중복 합치기** | 상세 → ✎ → **이 사업 삭제** | `biz_delete`(+전표는 override로 이동) |
| 확정 결과 학습 | 설정 탭 **[AI 학습]** 버튼(자동 학습 없음) | `learned_match` |
| 연도 확정 | 설정 탭 → 마감 | `year_lock` (변경 API 423 차단) |

되돌리기는 전부 **설정 탭 이력 4종**(수동 재배정 / 수동 추가 사업 / 사업 내용 수정 / **사업 삭제**)에서.
