# 통합 예산 프로그램 실행

저장소 루트의 `run_budget.py`가 최신 통합 앱을 실행합니다. 초기 버전인 루트 `app.py`를 실행하지 마세요. Python 3.12 또는 3.13을 권장합니다.

## 처음 설치

GitHub에서 main을 받아 압축을 풀고, 저장소 폴더에서 터미널을 엽니다.

macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r "2026-09-08_예산예측프로그램/requirements.txt"
.venv/bin/python run_budget.py
```

Windows:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r "2026-09-08_예산예측프로그램\requirements.txt"
.venv\Scripts\python run_budget.py
```

이후에는 마지막 실행 명령만 쓰면 됩니다. 기본 주소는 http://127.0.0.1:8501 이며 종료는 터미널에서 Ctrl+C입니다. 라이브러리 설치 후 실행·매칭·계산은 로컬에서 처리합니다. 기존 데이터가 있는 작업 폴더는 삭제하거나 새 다운로드로 덮어쓰지 말고 Git으로 코드만 갱신하세요.

## 사업 매칭 → 표준화 → 중장기 예산

1. 메뉴 **예산 실적 집계 → 사업 실적 연결**을 엽니다.
2. **매칭 도구 실행 / 다운로드**를 펼칩니다. 화면 안에서 실행하거나 HTML을 내려받아 브라우저로 엽니다.
3. RAW, 양식2(손익), 양식3(자본)를 올립니다. 이번 과거 실적 검증에서는 최종 실적금액 대조 모드를 사용합니다. 담당자 보정이 있으면 보정 Excel 또는 별도 보관한 보정 JSON을 함께 선택합니다. 공개 코드에는 실제 보정 데이터가 들어 있지 않습니다.
4. 집계표 생성 후 **팀 점검용 결과 JSON 다운로드**를 누릅니다. 예전 JSON에 전기일 연도/원천합계가 없으면 최신 도구로 다시 생성해야 합니다.
5. 같은 **사업 실적 연결** 화면에서 JSON을 올립니다. 원천순액·연결금액·제외·미배정과 사업별 내역을 확인하고 **배정분을 표준화·중장기 예산에 연결**을 누릅니다.
6. **예산 표준화** 또는 **중장기 예산 예측**에서 **연결한 사업 실적**을 선택합니다. 두 화면이 같은 연간 사업별 배정금액을 사용합니다. 기존 투자유형 분류 실적으로도 전환할 수 있으며 두 입력을 중복 합산하지 않습니다.
7. 정비등급 이력·일정·본사배분·팩터 등 예측에 필요한 별도 입력을 확인한 후 계산·엑셀 내보내기를 사용합니다.

현재 연결은 **배정된 사업만 사용하는 중간 점검용**입니다. 미배정·제외분은 예측 입력에서 빠지며 화면에 금액이 표시됩니다. 따라서 부분 연결 결과를 전체 예산 확정값으로 취급하면 안 됩니다. 다른 연도는 그 연도의 RAW/집계표/보정을 사용해 따로 검증·연결합니다. 여러 연도가 섞인 RAW는 연결 단계에서 차단합니다.

## 데이터 보존

- 원본 RAW/집계표/기존 `data_*.csv`, `matched_*.csv`, `classified_*.csv`를 이 연결 기능이 덮어쓰지 않습니다.
- 연결 결과는 최신 앱 폴더의 `checkpoint_data/`에 로컬 저장됩니다. 같은 연도를 다시 연결하면 활성 버전만 바꾸고 이전 파일은 보관합니다. 동일 결과를 재업로드해도 중복 합산하지 않습니다.
- `checkpoint_data/`, 실제 보정 JSON, 전표·검토 결과는 GitHub에 올리지 않습니다.
- 전표 날짜를 사업별로 임의 생성하지 않습니다. 연간 예측 입력은 JSON의 원천 전기일 연도와 사업별 배정금액으로 만듭니다.
