## A. `data_{연도}.csv` (본인→동료) ↔ zrfm2 원본
규격은 본인이 정제해 넘긴다고 규정. **우리 방침은 raw zrfm2 직접 사용**이므로, 대응 원본 컬럼만 표기.

| 규격 `data` 칸 | zrfm2 원본 컬럼(위치) | budget_app 취급 | 가능 |
|---|---|---|---|
| `거래처명` | 공급업체(15열) = **코드 숫자** | (미로드) | ⚠️ 코드만, 이름 아님 |
| `사업장`(손익센터 4자리) | 손익 센터(12열) | (미로드) | ✅ 추출 가능(로더 확장 필요) |
| `전기일`(날짜) | FM 전기일(5열) | (미로드) | ✅ 추출 가능(로더 확장 필요) |
| `전표헤더텍스트` | 텍스트(8열) | `사업명` | ✅ |
| `금액`(원) | FM 영역통화 금액(7열) | `금액원`(내부 `금액천원`=÷1000) | ✅ |
| `계정과목`(정규화) | 약정항목 텍스트(3열) + 계정코드(2열) | `과목정규`(별칭·계정코드 정규화) | ✅ |
| — | 기간/연도(4열) | `연도`(`2025.001`→`2025`) | 참고 |
| — | 참조 전표 번호(6열) | `전표번호` | 규격 data엔 없음 |
| — | 이름(9열)=지사명 / 이름(10열)=부서명(부) | `지사원문`→`처지사정규` | 규격 data엔 지사이름 없음(사업장 코드만) |

> 로더 확장 포인트: 현재 erp_loader는 2·3·4·6·7·8·9·10열만 로드. 규격 대응하려면 **5열(전기일)·12열(손익센터)·15열(공급업체)** 추가 로드 필요.

## B. `budget_{연도}.csv` (본인→동료) ↔ 계획본
규격은 본인이 파싱해 넘긴다고 규정. 우리 계획본(`양식1(월별)`) 대응.

| 규격 `budget` 칸 | budget_app 계획본 대응 | 가능 |
|---|---|---|
| `사업명` | 사업명(8열) | ✅ |
| `예산과목`(정규화) | 예산과목(7열, 별칭 정규화) | ✅ |
| `연예산 합계`(원) | 연예산(10열, 내부 천원 → ×1000) | ✅ |
| `예산귀속 \n부서코드`(줄바꿈 포함) | 부서코드(2열) | ✅ (칸 이름의 `\n` 주의) |
| `예산귀속\n부서명(처.지사)` | 처지사(3열) | ✅ (24개 지사 기준) |
| `예산코드`(계정코드) | 예산코드(6열) | ✅ |
| `속성`,`주관부서명`,`본부`,월별 | 속성(5열)·주관부서명(1열)·(본부 없음)·(월별 없음) | ⚠️ 일부 없음 |
| **`사업코드`** | — | ❌ **없음**(matched가 요구하나 계획에 부재) |

## C. `classified_{연도}.csv` (동료→본인) ★본인이 소비★
= `data` 6칸 그대로 + `투자유형_확정`.

| 칸 | budget_app 가능 | 비고 |
|---|---|---|
| `거래처명`·`사업장`·`전기일`·`전표헤더텍스트`·`금액`·`계정과목` | data와 동일(§A) | data를 그대로 통과 |
| **`투자유형_확정`**(8종+미분류) | ❌ **미구현(보류)** | LTSA·정기사업·노후설비개체·AX/DX·운영안정성 제고·환경강화·교육강화·보안강화 |

> **결론: 투자유형 담당 확정 전까지 classified 생성 불가** → 본인 대시보드·리포트·예측 연결 불가.

## D. `matched_{연도}.csv` (동료 내부) ↔ budget_app matched CSV
규격 §3-4 = `data` 6칸 + `사업코드` + `사업명` + `매칭확신도`.
budget_app 현재 14칸: `_erp_row·계정코드·예산과목원문·과목정규·지사원문·처지사정규·연도·전표번호·사업명·금액원·금액천원·매칭사업명·매칭확신도·구분`.

| 규격 matched 칸 | budget_app 대응 | 가능 |
|---|---|---|
| `거래처명` | (공급업체 코드, 로더 확장 시) | ⚠️ 코드만 |
| `사업장` | (손익센터, 로더 확장 시) / 현재 `처지사정규`(이름) | ⚠️ |
| `전기일` | (FM전기일, 로더 확장 시) | ✅(확장 필요) |
| `전표헤더텍스트` | `사업명`(zrfm2 텍스트) | ✅ |
| `금액`(원) | `금액원` | ✅ |
| `계정과목` | `과목정규` | ✅ |
| **`사업코드`** | — | ❌ **없음** |
| `사업명`(매칭된 계획 사업명) | `매칭사업명` | ✅ |
| `매칭확신도` | `매칭확신도` | ✅ |
| (부가) 구분·전표번호 등 | 있음 | 규격엔 없음 |

## E. 축·단위·네이밍 차이 요약
| 항목 | 규격 | budget_app | 처리 |
|---|---|---|---|
| 금액 단위 | 원(₩) | 천원 | 경계 ×1000 / ÷1000 |
| 손익/자본 축 | 파일에 없음(연도별만) | 손익·자본 분리(파일·config·산출물) | **분리 유지** 결정(파일명 합의 대상) |
| 파일명 | `data_2025.csv` 등 | `matched_2025_손익.csv` 등 | 통합 시 재합의 |
| 인코딩 | utf-8-sig | utf-8-sig | 동일 ✅ |
| 결측 | 빈 값/NaN, `pd.isna` 방어 | 동일(pandas 3.0 None→NaN 가드) | 동일 ✅ |
| 사업장→지사 | 손익센터 코드(앞3자리 규칙) | 지사이름+부서명 정규화 | 어댑터가 budget_csv로 코드→지사 매핑 구성 |
