- 결론: 엔진은 zrfm2 기준 정확. 차이는 데이터소스 범위·분류 정책 → **Step 3 구성 선택으로 사용자 통제**.

## Step 3 — 구성 선택 + 미반영
### 3a. UI (app.py render_actual_tab)
계획탭과 동일한 편집기를 동일 config 공유로 추가:
- ② 지사 구성 (지사구성_{year}.json)
- ③ 예산과목 구성 (과목구성_{year}_{budget}.json)
- 기존 ②~⑥ → ④계획본 / ⑤ERP / ⑥마스터 / ⑦정책 / ⑧실행 로 재배치.

### 3b. 스코프 필터 + 미반영 (matching / pipeline_actual)
- `selected_depts` = 포함=True 지사, `budget_selected` = 포함=True 과목(현행 budget_items).
- `budget_all` = 해당 예산 전체 과목(포함무관), `other_budget_items` = 반대 예산 전체 과목.
- ERP 전표 분류(erp_annotated["구분"]):
  - in-scope(과목∈budget_selected AND 처지사∈selected_depts) → 계획집행/신규/신규(소액집행)
  - 과목∈other_budget_items → "" (타예산, zrfm2_V1 공란)
  - 그 외(미선택 자본과목·미분류·미매핑 지사) → **"미반영"**
- in-scope 전표만 매칭/집계 대상(groups/new_rows). 미반영 금액은 종합표·양식1에 미포함.
- **총액 정합**: 종합표 총액 + 미반영 총액 + 타예산 = ERP 전체.

### 3c. zrfm2_V1 반영구분 열
- 기존 R(18)=사업명(매칭), S(19)=매칭확신도 유지.
- **T(20)=반영구분** 추가 = erp_annotated["구분"] (계획집행/신규/미반영/공란).
- 미반영 행은 시각 강조(연회색 음영) 선택.

### 3d. 검토리포트 / 요약
