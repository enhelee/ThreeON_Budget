# 예산 자동 분석 프로그램 — 설계 명세서

- 작성일: 2026-07-21
- 프로젝트: 중장기 예산 소요 전망 자동 집계
- 형태: 로컬 웹앱(Streamlit) — 파일 업로드 → 자동 분석 → 엑셀 산출물 다운로드

---

## 1. 목적

지역난방공사 예산 담당자가 **계획 양식1(월별)** 과 **ERP(SAP) 추출 zrfm2** 파일을 업로드하면,
지사별·예산과목별 집계를 자동 계산하여 **계획/실적 × 손익/자본** 4종 집계표와 부속 산출물을
버튼 클릭 한 번으로 생성한다. 기존 엑셀 수식(SUMIFS)의 오류·미완성 부분을 자동화 로직으로
개선·복구한다.

---

## 2. 입력 및 내장 기준데이터

### 2.1 사용자 업로드 파일
| 파일 | 시트 | 용도 |
|---|---|---|
| 손익예산_최종본 (양식1 월별) | `양식1(월별)` | 계획 원천데이터 (손익·자본 모두 포함) |
| zrfm2.XLSX | `Sheet1` | 실적 원천데이터 (ERP 추출) — **파일명 반드시 `zrfm2.XLSX`** |

- **계획 실행 시**: 양식1(월별) 1개 업로드
- **실적 실행 시**: 해당 연도 계획 양식1(월별) + zrfm2 2개 업로드
  (계획대비실적 A~H열을 계획 데이터로 채우기 위해 계획본이 필요)

### 2.2 내장 기준데이터 (프로그램에 포함, `손익예산26_최종본`에서 추출·고정)
- `예산코드` 시트: 예산코드(A) → 예산과목명(B) / 주관부서(C,D) / **속성(E)**
- `부서코드` 시트: 부서코드(A) → 부서명(B) / **처·지사(C)**

기준데이터는 `reference/` 폴더의 엑셀 또는 직렬화 파일로 동봉하며, UI에서 교체 업로드도 허용한다.

### 2.3 양식1(월별) 컬럼 정의 (행3 = 헤더, 행4~ = 데이터)
| 열 | 의미 | 열 | 의미 |
|---|---|---|---|
| A | 주관부서명 | B | 예산귀속 부서코드 |
| C | 예산귀속 부서명(처.지사) | D | 예산귀속 부서명(부) |
| E | 속성 | F | 예산코드 |
| G | 예산과목 | H | 사업명 |
| I | 산출내역 | **J** | **연예산 합계** |
| K~V | 1월~12월 | — | — |

### 2.4 zrfm2 컬럼 정의 (행1 = 헤더, 행2~ = 데이터)
| 열 | 의미 | 매칭 역할 |
|---|---|---|
| A | 자금텍스트(속성) | 참고 |
| B | 약정항목(예산코드) | 참고 |
| **C** | 약정항목텍스트 = **예산과목명** | **1순위 매칭키** |
| D | 기간/연도 (예 `2025.001`) | **연도 검증** |
| **G** | 지급예산금액 (**원 단위**) | **실적금액(÷1000 → 천원)** |
| **H** | 텍스트 = **사업 설명** | **3순위 매칭(사업명 유사도)** |
| I, J | 이름/부서 텍스트 | 참고(부서 보조 확인) |
| **P** | 자금관리센터(부서코드) | **2순위 매칭(→부서코드→처·지사)** |

## 3. UI 흐름 (Streamlit)

실행: 바탕화면 `분석프로그램_실행.bat` 더블클릭 → 로컬 서버 기동 → 브라우저 자동 오픈.

```
┌ ① 양식 다운로드 ────────────────────────────┐
│  [양식1(월별) 템플릿 ⬇]  [zrfm2 안내 ⬇]        │
│  ⚠ zrfm2는 파일명을 반드시 'zrfm2.XLSX'로 저장  │
├ ② 분석 대상 선택 ───────────────────────────┤
│  구분:  ( )계획   ( )실적      대상연도: [2026 ▾] │
├ ③ 파일 업로드 (선택에 따라 칸 표시) ──────────┤
│  계획양식1: [drag&drop]   zrfm2: [drag&drop]     │
├ ④ 옵션 ────────────────────────────────────┤
│  사업명 유사도 임계값: [====|====] 80%           │
├ ⑤ 분석 실행 ───────────────────────────────┤
│  [ 분석 실행 ]  → 진행률바 → 연도검증 결과       │
├ ⑥ 결과 요약 & 다운로드 ──────────────────────┤
│  집계 총액 / 매칭률 / 미매칭 건수 표시           │
│  [개별 다운로드]  [전체 ZIP 다운로드]            │
└─────────────────────────────────────────────┘
```

### 연도 검증
- zrfm2 D열 앞 4자리 연도의 최빈값이 선택한 `대상연도`와 다르면 → 검토리포트 상단에 경고 기록(진행은 계속).
- 양식1은 명시적 연도 컬럼이 없으므로 파일명·헤더 텍스트에서 연도 추정, 불확실 시 리포트에 "연도 확인 불가" 명시.

## 4. 손익 / 자본 분류

- 각 예산과목의 **속성(예산코드 E열)이 `자산` 이면 자본**, 그 외(`제조/일반/영업외/건가…`)는 **손익**.
- 단, **최종 귀속은 각 종합표 템플릿의 예산과목 목록을 기준**으로 확정한다(아래 §7).
  - 손익 종합표 목록(양식2 기준)에 있는 과목 → 손익 집계표
  - 자본 종합표 목록(양식3 기준)에 있는 과목 → 자본 집계표
- 두 목록 어디에도 없는 예산과목이 데이터에 나오면 → **검토리포트 "미분류 예산과목" 목록**에 기록(집계 누락 방지).

## 5. 계획 처리 로직 (양식1 → 계획 종합표)

1. 양식1(월별) 4행부터 유효행(예산과목·부서·금액 존재) 로드.
2. 각 예산과목별로 §7 종합표 지사 컬럼에 대해 **연예산 합계(J) 를 처·지사(C) 기준 집계**.
3. **심의대상 분리** — `수선유지비-건물/구축물`, `수선유지비-열원보완및개선` 두 과목만:
   - 사업(행) 단위 **연예산 ≥ 50,000천원 → 5천만원 이상(심의대상)**, 미만 → 5천만원 미만.
   - (원본 종합표의 끊긴 `양식1!Y:$Y="O"` 수식 대신, **자동 계산된 심의대상 플래그 열**을 데이터 시트에 추가하고 종합표가 이를 참조하도록 복구)
4. 출력 워크북에 `양식1(월별)` 데이터 시트 + `종합표`(SUMIFS 수식) 동시 포함 → 엑셀에서 재계산·검증 가능.

## 6. 실적 처리 로직 (zrfm2 → 계획대비실적 → 실적 종합표)

### 6.1 계획대비실적 시트 A~H 채우기 (계획본에서 매핑)
| 계획대비실적 열 | 원천(양식1) |
|---|---|
| A 연번 | 순번 자동 |
| B 예산과목 | G 예산과목 |
| C 속성 | E 속성 |
| D 주관부서명 | A 주관부서명 |
| E 예산귀속 부서명(처.지사) | C |
| F 예산귀속 부서명(팀) | D 부서명(부) |
| G 사업명 | H 사업명 |
| H 연예산(A) | J 연예산 합계 |
| I 최종 실적금액(B) | §6.2 매칭 결과 |

### 6.2 실적금액(I열) 매칭 알고리즘
각 zrfm2 행을 계획 사업(계획대비실적 행)에 배정:

1. **1순위 — 예산과목**: zrfm2 C == 계획 B (완전 일치 필수).
2. **2순위 — 처·지사**: zrfm2 P(부서코드) → 부서코드 시트 → 처·지사, 계획 E와 일치 필수.
3. **3순위 — 사업명**: 위 두 조건을 만족하는 계획 사업 후보 중, zrfm2 H(설명)와 계획 G(사업명)의
   **한글 키워드 병행 + 문자열 유사도**가 **임계값(기본 80%, UI 조정) 이상**인 최고 점수 사업에 배정.
4. 배정된 계획 행의 I열에 zrfm2 G(÷1000, 원→천원) 를 **합산**(다수 zrfm2 → 1 계획행 가능).

**미매칭 처리 (사용자 결정 반영):**
- 1·2순위(과목+부서)는 맞으나 3순위 유사도 < 임계값인 행 →
  해당 **부서·과목의 '미지정(사업명 미확정)' 계획행에 합산**하여 종합표 실적 총액이 zrfm2 총액과 일치하도록 보장.
- 1순위 또는 2순위 자체가 불일치(과목·부서 매칭 실패) → 집계 제외, **검토리포트 "미매칭 실적" 목록**에 기록.

### 6.3 산출물 zrfm2_V1
- zrfm2 원본 A~P열 **그대로 유지** + **R열 = 배정된 계획 사업명**(미지정/미매칭은 해당 사유 표기).
- (Q열은 원본 여백 보존, 배정 결과는 R열에 기록)

## 7. 종합표 생성 (서식·수식)

각 종합표는 **참조 파일을 템플릿으로 복사**하여 헤더·레이블·서식(색/테두리/병합)을 원본 그대로 유지하고
데이터/수식만 채운다.

### 7.1 손익 계획 종합표 (`손익예산26_최종본` 종합표 기준)
- A·B·C열 및 1~7행 **원본 유지**. 부서 컬럼 D~AG(본사 처 6 + 소계 + 지사그룹별 소계 + 합계).
- 예산과목 행(9과목): 수선유지비-건물/구축물, -열원정기점검, -열원경상정비, -열원정기유지보수,
  -열원보완및개선, -비저장품(보수자재), -소모품(자재공기구), 계, 지급수수료-열원점검수수료.
- 건물/구축물·열원보완및개선은 5천만원 미만/이상 2행.
- SUMIFS(양식1 J / G=과목 / C=부서), 심의대상은 심의대상 플래그 추가.

### 7.2 손익 실적 종합표 (양식2 기준)
- A·B열 및 1~5행 **원본 유지**. 부서 컬럼 C~AE(플랜트기술처·안전처·통합운영처·건설처·미래사업처 순 + 지사).
- 예산과목 행(6과목): 수선유지비-건물/구축물, -열원정기점검, -열원경상정비, -열원정기유지보수,
  -열원보완개선및기타, 계, 지급수수료-열원점검수수료.
- SUMIFS(계획대비실적 I / B=과목 / E=부서).

### 7.3 자본 실적 종합표 (양식3 기준) — 예산과목 11개
| 대분류 | 예산과목 |
|---|---|
| 자산 | 건물 / 구축물 / 기계장치 / 공구와기구-열원시설공기구 |
| 예비품 | 저장품-열원(보수) / 건설중인자산-재생고온부품 / 건설중인자산-자산화예비품 |
| A급 정비 | 외주비-열원정기점검 |
| 건설공사 | 외주비-열원공사비 / 재료비-열원자재비 / 외주비-열원기술용역비 |

### 7.4 자본 계획 종합표 (신규 조합)
- **열(부서)** 은 양식3 종합표 A·B/부서 레이아웃(C~AE)을 참조.
- **행(예산과목)** 은 §7.3 자본 11개 과목 사용, 헤더 스타일은 손익 계획 종합표 1~7행 스타일 적용.
- SUMIFS(양식1 J / G=과목 / C=부서). (자본은 심의대상 분리 없음)

### 7.5 원본 수식 개선(버그 수정)
- 손익 계획 종합표 `계` 행의 소계 합계범위 오류(`SUM(T8:T14)`, `SUM(X8:X14)`, `AF8:AF14`, `AG8:AG14`)를
  실제 과목행 끝(16행)까지로 정정 → `SUM(T8:T16)` 등.
- 지사그룹 소계/합계 참조 일관성 검증 후 정정.

## 8. 계획대비실적 비교표 (추가 산출물)

- 같은 연도의 계획·실적이 모두 준비된 경우 생성.
- 지사별·예산과목별로 **계획(A) / 실적(B) / 차이(B−A) / 달성률(B/A %)** 을 한 시트에 표기.
- 손익·자본 각각 생성.

## 10. 검토리포트 시트 구성

1. **연도검증**: 선택연도 vs 데이터 감지연도, 불일치 경고.
2. **미매칭 실적**: 과목/부서 매칭 실패 zrfm2 행 전체(원본 열 + 사유).
3. **사업명 미확정(미지정 배분)**: 과목·부서는 맞으나 유사도 < 임계값으로 '미지정'에 합산된 행 + 유사도 점수.
4. **매칭 신뢰도**: 배정된 각 zrfm2 행의 배정 사업명·유사도 점수(정렬).
5. **미분류 예산과목**: 손익/자본 종합표 목록에 없는 과목 목록.
6. **미매칭 부서코드**: 부서코드 시트에 없는 zrfm2 P / 양식1 부서.
7. **미입력 열/필드**: 필수 필드 누락 행(예산과목·부서·금액 공란) 목록.

## 11. 기술 스택 & 모듈 구조

- Python 3.14, openpyxl(서식 유지), pandas(집계), rapidfuzz(유사도), streamlit(UI).
- 모듈(단일 책임 분리):
  - `config.py` — 부서 컬럼 순서/종합표 템플릿 매핑/과목 목록/기본 임계값 상수
  - `reference_data.py` — 예산코드·부서코드 로딩/조회 (코드→과목/속성, 코드→처·지사)
  - `loaders.py` — 양식1·zrfm2 로드 및 정규화(DataFrame)
  - `classifier.py` — 손익/자본 분류, 심의대상 판정
  - `plan_aggregator.py` — 계획 집계
  - `actual_matcher.py` — zrfm2→계획 매칭(유사도, 키워드)
  - `actual_aggregator.py` — 실적 집계
  - `comparison.py` — 계획대비실적 비교
  - `report.py` — 검토리포트 생성
  - `excel_writer.py` — 템플릿 복사 + 서식 유지 출력, 수식 작성
  - `validators.py` — 연도/부서/과목 검증
  - `app.py` — Streamlit UI (조립만)
- 각 모듈은 순수 함수 위주로 작성하여 pytest 단위 테스트 가능하게 한다.

## 12. 에러 처리 / 엣지 케이스

- 파일명이 `zrfm2.XLSX`가 아니면 경고(진행은 허용하되 안내).
- 시트명 부재/헤더 위치 다름 → 명확한 오류 메시지.
- 금액이 음수(비용 역인식)여도 그대로 합산.
- 종합표에 없는 지사(공통주관/공통순수/비서부 등) → 검토리포트 기록 후 집계 제외.
- 유사도 라이브러리 미설치 시 문자열 기본 유사도로 폴백.

  붙이기 쉽도록 설계만 열어둔다.

## 14. 성공 기준

- 계획 실행 시 손익·자본 계획 집계표 2종의 종합표 합계가 양식1 원천 합계와 일치.
- 실적 실행 시 실적 종합표 총액 = zrfm2 G열 합계(÷1000, 매칭+미지정 포함).
- zrfm2_V1 R열에 배정 결과 100% 기록(미매칭 사유 포함).
- 검토리포트에 미매칭/미분류/연도불일치가 빠짐없이 표기.
- 원본 종합표 서식(레이블·색·테두리) 유지 및 SUMIFS 재계산 정상.
